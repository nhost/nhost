The Nhost Rust SDK (`nhost`) runs both on native targets and in the browser via
WebAssembly. This quickstart builds a client-side [Yew](https://yew.rs) app that
signs a user in and reads and writes their private **notes** over GraphQL — the
same flow as the JavaScript quickstarts, in Rust.

### Create Project

If you haven't, please create a project through the [Nhost Dashboard](https://app.nhost.io).

### Setup Database

Navigate to the **SQL Editor** of the database and run the following SQL to
create a `notes` table. Each note belongs to a user (`user_id` references the
built-in `auth.users` table).

```sql SQL Editor
CREATE TABLE notes (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id    uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  title      text NOT NULL,
  content    text NOT NULL DEFAULT '',
  created_at timestamptz NOT NULL DEFAULT now()
);
```

:::caution
Make sure the option `Track this` is enabled.
:::

### Permissions

The GraphQL engine checks every request against the permissions of the
caller's role, using the user ID in their access token. Select the `notes`
table, click **Edit Permissions**, and set these for the `user` role:

- **insert**: under **Column insert permissions**, select `title` and
  `content`. Under **Column presets**, set `user_id` to `X-Hasura-User-Id`, so
  each note belongs to the user who created it.
- **select**: under **Row select permissions**, choose **With custom check**
  and add the rule `user_id` `_eq` `X-Hasura-User-Id`. Under **Column select
  permissions**, select `id`, `title`, `content` and `created_at`.

### Create a user

The app signs users in with an email and password, so create one to sign in
as: open **Auth**, click **Create User**, and enter an email (for example
`user@example.com`) and a password.
New projects only let users sign in once their email is verified, so open the
new user and tick **Verified** next to their email.

Because `notes` requires a session, the app loads them **after** the user signs
in — there's no public data to show beforehand.

### Setup the Application

Create a client-side Yew app and install [Trunk](https://trunkrs.dev), the
WebAssembly bundler, plus the `wasm32-unknown-unknown` target:

```bash Terminal
cargo new --bin my-yew-app
cd my-yew-app

cargo install trunk
rustup target add wasm32-unknown-unknown
```

### Install the Nhost package

Add the SDK with its browser feature enabled, alongside Yew and the async glue.
The `nhost` crate is not yet published on crates.io, so install it from the
Nhost repository.

```bash Terminal
cargo add yew --features csr
cargo add web-sys --features HtmlInputElement
cargo add wasm-bindgen-futures
cargo add serde --features derive
cargo add serde_json
cargo add console_error_panic_hook

# default-features = false drops the native rustls-tls backend (the browser
# handles TLS); the `wasm` feature enables the browser-compatible pipeline and
# the localStorage session store.
cargo add nhost --git https://github.com/nhost/nhost.git \
  --no-default-features --features wasm
```

Your `Cargo.toml` dependencies should look like this:

```toml title="Cargo.toml"
[dependencies]
yew = { version = "0.21", features = ["csr"] }
nhost = { git = "https://github.com/nhost/nhost.git", version = "0.0.0-dev", default-features = false, features = ["wasm"] }
web-sys = { version = "0.3", features = ["HtmlInputElement"] }
wasm-bindgen-futures = "0.4"
serde = { version = "1", features = ["derive"] }
serde_json = "1"
console_error_panic_hook = "0.1"
```

The repository dependency resolves the crate from `packages/nhost-rust` on the
default branch, because `nhost` is not on crates.io yet. It therefore tracks
`main` rather than a fixed release; add a `rev` or `tag` if you need a
reproducible build. Once `nhost` is published, replace its `git` key with
`version = "<current published version>"`, or rerun the command without `--git`
to let `cargo add` select the current release.

```rust
use nhost::auth::SignInEmailPasswordRequest;
use nhost::session::{LocalStorageStore, MemoryStore};
use nhost::Nhost;
use serde::Deserialize;
use serde_json::{json, Value};
use wasm_bindgen_futures::spawn_local;
use web_sys::HtmlInputElement;
use yew::prelude::*;

// The custom check on `notes` scopes this to the signed-in user automatically.
const LIST_NOTES: &str = "query { notes(order_by: {created_at: desc}) { id title content } }";

// `user_id` is filled in by the column preset, so we only send title + content.
const INSERT_NOTE: &str = "mutation ($title: String!, $content: String!) { \
    insert_notes_one(object: {title: $title, content: $content}) { id } \
}";

#[derive(Clone, PartialEq, Deserialize)]
struct Note {
    id: String,
    title: String,
    content: String,
}

#[derive(Deserialize)]
struct NotesData {
    notes: Vec<Note>,
}

// Point at a cloud project by replacing <subdomain> and <region>. For a local
// backend, use `subdomain: "local"` and `region: "local"`.
//
// `build` validates the project fields and the service URLs it derives from
// them, so it returns `Result` — it fails if you leave the placeholders below
// in place.
fn make_client() -> Nhost {
    let builder = Nhost::builder().subdomain("<subdomain>").region("<region>");
    // Keep the session in localStorage so it survives a page reload. Without a
    // session store the client keeps no session, and requests after sign-in
    // would carry no token. Browsers can disable localStorage, so fall back to
    // memory rather than failing to start.
    let builder = match LocalStorageStore::new() {
        Some(store) => builder.session_store(store),
        None => builder.session_store(MemoryStore::default()),
    };
    builder
        .build()
        .expect("subdomain and region must be a valid Nhost project")
}

#[function_component(App)]
fn app() -> Html {
    // The browser client and its futures are `!Send`, so keep it in an `Rc`.
    let client = use_memo((), |_| make_client());
    let notes = use_state(Vec::<Note>::new);
    let email = use_state(String::new);
    let password = use_state(String::new);
    let title = use_state(String::new);
    let content = use_state(String::new);
    let status = use_state(String::new);

    // Sign in, then load this user's notes.
    let on_signin = {
        let client = client.clone();
        let notes = notes.clone();
        let email = email.clone();
        let password = password.clone();
        let status = status.clone();
        Callback::from(move |e: SubmitEvent| {
            e.prevent_default();
            let client = client.clone();
            let notes = notes.clone();
            let status = status.clone();
            let req = SignInEmailPasswordRequest {
                email: (*email).clone(),
                password: (*password).clone(),
            };
            status.set("Signing in…".to_string());
            spawn_local(async move {
                match client.auth.sign_in_email_password(req).await {
                    Ok(_) => {
                        // The client saved the session in localStorage; later
                        // requests attach its token and refresh it.
                        status.set("Signed in".to_string());
                        if let Ok(data) = client.graphql.query(LIST_NOTES).send::<NotesData>().await
                        {
                            notes.set(data.notes);
                        }
                    }
                    Err(err) => status.set(format!("Sign-in failed: {err}")),
                }
            });
        })
    };

    // Add a note, then reload the list.
    let on_add = {
        let client = client.clone();
        let notes = notes.clone();
        let title = title.clone();
        let content = content.clone();
        Callback::from(move |e: SubmitEvent| {
            e.prevent_default();
            let client = client.clone();
            let notes = notes.clone();
            let vars = json!({ "title": (*title).clone(), "content": (*content).clone() });
            title.set(String::new());
            content.set(String::new());
            spawn_local(async move {
                let inserted = client
                    .graphql
                    .query(INSERT_NOTE)
                    .variables(vars)
                    .send::<Value>()
                    .await;
                if inserted.is_ok() {
                    if let Ok(data) = client.graphql.query(LIST_NOTES).send::<NotesData>().await {
                        notes.set(data.notes);
                    }
                }
            });
        })
    };

    let oninput = |setter: UseStateHandle<String>| {
        Callback::from(move |e: InputEvent| {
            let input: HtmlInputElement = e.target_unchecked_into();
            setter.set(input.value());
        })
    };

    html! {
        <main>
            <h1>{ "My notes" }</h1>

            <h2>{ "Sign in" }</h2>
            <form onsubmit={on_signin}>
                <input type="email" placeholder="email"
                    value={(*email).clone()} oninput={oninput(email.clone())} />
                <input type="password" placeholder="password"
                    value={(*password).clone()} oninput={oninput(password.clone())} />
                <button type="submit">{ "Sign in" }</button>
            </form>
            <p>{ (*status).clone() }</p>

            <h2>{ "New note" }</h2>
            <form onsubmit={on_add}>
                <input type="text" placeholder="title"
                    value={(*title).clone()} oninput={oninput(title.clone())} />
                <input type="text" placeholder="content"
                    value={(*content).clone()} oninput={oninput(content.clone())} />
                <button type="submit">{ "Add" }</button>
            </form>

            <ul>
                { for notes.iter().map(|n| html! {
                    <li key={n.id.clone()}>
                        <strong>{ &n.title }</strong>{ format!(": {}", n.content) }
                    </li>
                }) }
            </ul>
        </main>
    }
}

fn main() {
    console_error_panic_hook::set_once();
    yew::Renderer::<App>::new().render();
}
```

:::note
Randomness for PKCE uses `getrandom`'s JS backend on the web. The SDK enables
`getrandom`'s `wasm_js` feature automatically, so no application-specific
backend configuration is required.
:::

### The end

Run your project with `trunk serve` and navigate to `http://localhost:8080` in
your browser. Sign in, and your notes appear below the form.
