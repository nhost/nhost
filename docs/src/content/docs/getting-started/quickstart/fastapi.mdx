The Nhost Python SDK (`nhost`) is an async-first client for Nhost's Auth,
Storage, GraphQL, and Functions services. This quickstart wires it into a
[FastAPI](https://fastapi.tiangolo.com) service that signs a user in and reads
and writes their private **notes** over GraphQL — the server-side counterpart to
the JavaScript quickstarts.

### Create Project

If you haven't, please create a project through the [Nhost Dashboard](https://app.nhost.io).

### Setup Database

Navigate to the **SQL Editor** of the database and run the following SQL to
create a `notes` table. Each note belongs to a user (`user_id` references the
built-in `auth.users` table).

```sql SQL Editor
CREATE TABLE notes (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id    uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  title      text NOT NULL,
  content    text NOT NULL DEFAULT '',
  created_at timestamptz NOT NULL DEFAULT now()
);
```

:::caution
Make sure the option `Track this` is enabled.
:::

### Permissions

The GraphQL engine checks every request against the permissions of the
caller's role, using the user ID in their access token. Select the `notes`
table, click **Edit Permissions**, and set these for the `user` role:

- **insert**: under **Column insert permissions**, select `title` and
  `content`. Under **Column presets**, set `user_id` to `X-Hasura-User-Id`, so
  each note belongs to the user who created it.
- **select**: under **Row select permissions**, choose **With custom check**
  and add the rule `user_id` `_eq` `X-Hasura-User-Id`. Under **Column select
  permissions**, select `id`, `title`, `content` and `created_at`.

### Create a user

The service signs users in with an email and password, so create one to sign
in as: open **Auth**, click **Create User**, and enter an email (for example
`user@example.com`) and a password.
New projects only let users sign in once their email is verified, so open the
new user and tick **Verified** next to their email.

### Configure the Nhost client and read and write notes

The service creates one Nhost client when it starts. `/signin` returns an
access token, and `/notes` expects it back in the `Authorization` header.
`with_access_token` returns a handle to the client that sends that token with
the handler's GraphQL requests, so they run with the caller's permissions. The
client has no session store, so it never keeps a user's session between
requests.

<Tabs>
  <TabItem label="main.py">
```python
from collections.abc import AsyncIterator
from contextlib import asynccontextmanager
from typing import Annotated, cast

from fastapi import Depends, FastAPI, Header, HTTPException, Request
from fastapi.responses import JSONResponse
from nhost import GraphQLExecutionError, HTTPError, Nhost
from nhost.auth import SignInEmailPasswordRequest
from pydantic import BaseModel

# The custom check on `notes` returns only the caller's own notes.
LIST_NOTES = "query { notes(order_by: {created_at: desc}) { id title content } }"

# The column preset fills in `user_id`, so we only send the title and content.
INSERT_NOTE = """
mutation ($title: String!, $content: String!) {
  insert_notes_one(object: {title: $title, content: $content}) { id }
}
"""


@asynccontextmanager
async def lifespan(app: FastAPI) -> AsyncIterator[None]:
    # Replace <subdomain> and <region> with your project's values. For a local
    # backend, use "local" for both.
    async with Nhost(subdomain="<subdomain>", region="<region>") as nhost:
        app.state.nhost = nhost
        yield


app = FastAPI(lifespan=lifespan)


@app.exception_handler(GraphQLExecutionError)
async def graphql_error(request: Request, error: GraphQLExecutionError) -> JSONResponse:
    # The GraphQL engine rejects an expired or invalid access token with the
    # `invalid-jwt` code, so the caller needs to sign in again.
    codes = {(e.extensions or {}).get("code") for e in error.errors}
    status_code = 401 if "invalid-jwt" in codes else 502
    return JSONResponse(status_code=status_code, content={"detail": str(error)})


class SignIn(BaseModel):
    email: str
    password: str


class Token(BaseModel):
    access_token: str


class NewNote(BaseModel):
    title: str
    content: str = ""


class NoteId(BaseModel):
    id: str


class Note(NoteId):
    title: str
    content: str


class InsertNoteData(BaseModel):
    insert_notes_one: NoteId | None


class ListNotesData(BaseModel):
    notes: list[Note]


def nhost_client(request: Request) -> Nhost:
    return cast(Nhost, request.app.state.nhost)


def caller(
    nhost: Annotated[Nhost, Depends(nhost_client)],
    authorization: Annotated[str | None, Header()] = None,
) -> Nhost:
    """The client, sending the caller's access token with each request."""
    scheme, _, token = (authorization or "").partition(" ")
    if scheme.casefold() != "bearer" or not token.strip():
        raise HTTPException(
            status_code=401,
            detail="missing Authorization: Bearer <access token> header",
            headers={"WWW-Authenticate": "Bearer"},
        )
    return nhost.with_access_token(token.strip())


@app.post("/signin")
async def signin(body: SignIn, nhost: Annotated[Nhost, Depends(nhost_client)]) -> Token:
    try:
        response = await nhost.auth.sign_in_email_password(
            body=SignInEmailPasswordRequest(email=body.email, password=body.password)
        )
    except HTTPError as error:
        raise HTTPException(status_code=error.status, detail=str(error)) from error

    session = response.body.session
    if session is None:
        raise HTTPException(status_code=401, detail="sign-in needs another step, such as MFA")
    return Token(access_token=session.access_token)


@app.post("/notes")
async def create_note(body: NewNote, nhost: Annotated[Nhost, Depends(caller)]) -> NoteId:
    result = await nhost.graphql.request(
        INSERT_NOTE,
        variables={"title": body.title, "content": body.content},
        response_type=InsertNoteData,
    )
    if result.body.data is None or result.body.data.insert_notes_one is None:
        raise HTTPException(status_code=502, detail="Nhost returned no inserted note")
    return result.body.data.insert_notes_one


@app.get("/notes")
async def list_notes(nhost: Annotated[Nhost, Depends(caller)]) -> list[Note]:
    result = await nhost.graphql.request(LIST_NOTES, response_type=ListNotesData)
    if result.body.data is None:
        raise HTTPException(status_code=502, detail="Nhost returned no notes data")
    return result.body.data.notes
```
  </TabItem>
</Tabs>

:::note
The token is sent as-is: the handle never stores or refreshes it. Access tokens
expire after 15 minutes by default; the GraphQL engine then rejects the token,
the service answers `401`, and the caller signs in again for a new one. To keep users' sessions on the server instead, give the client a
`multi_user_session_store` and pick the user for each request with
`with_user_id`; see the [SDK reference](/reference/python/nhost-python/main).
:::

### The end

Run your service with `uv run uvicorn main:app --reload` (or
`uvicorn main:app --reload` inside the pip virtualenv), then sign in as the user
you created and use the access token it returns:

```bash Terminal
TOKEN=$(curl -sS -X POST localhost:8000/signin \
  -H 'Content-Type: application/json' \
  -d '{"email":"user@example.com","password":"<password>"}' | jq -r .access_token)

curl -X POST localhost:8000/notes \
  -H "Authorization: Bearer $TOKEN" \
  -H 'Content-Type: application/json' \
  -d '{"title":"Hello","content":"My first note"}'
curl localhost:8000/notes -H "Authorization: Bearer $TOKEN"
```
