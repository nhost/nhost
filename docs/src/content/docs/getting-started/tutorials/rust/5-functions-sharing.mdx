## Share a note with a collaborator

Add a `note_collaborators` table in the **SQL Editor**:

```sql SQL Editor
CREATE TABLE public.note_collaborators (
  note_id uuid NOT NULL REFERENCES public.notes (id) ON DELETE CASCADE,
  user_id uuid NOT NULL REFERENCES auth.users (id) ON DELETE CASCADE,
  role    text NOT NULL DEFAULT 'viewer' CHECK (role IN ('viewer', 'editor')),
  PRIMARY KEY (note_id, user_id)
);
```

Track it, then create **both** relationships **before** setting the filters
below (Database → each table → **Relationships**):

- a `collaborators` **array** relationship on `notes` → `note_collaborators`, and
- a `note` **object** relationship on `note_collaborators` → `notes`.

Order matters and the names matter: the `notes` filters reference
`collaborators` and the `note_collaborators` check references `note`, so if a
relationship is missing or mis-named the permission won't save
(`"collaborators" does not exist` / `"note" does not exist`).

Now update the `notes` permissions so collaborators can see and edit shared
notes — this is the one place the owner-only rule opens up:

- **notes → select** filter — owner **or** any collaborator:

  ```json
  { "_or": [
      { "user_id": { "_eq": "X-Hasura-User-Id" } },
      { "collaborators": { "user_id": { "_eq": "X-Hasura-User-Id" } } }
  ]}
  ```
- **notes → update** filter — owner **or** an `editor` collaborator:

  ```json
  { "_or": [
      { "user_id": { "_eq": "X-Hasura-User-Id" } },
      { "collaborators": { "_and": [
          { "user_id": { "_eq": "X-Hasura-User-Id" } },
          { "role": { "_eq": "editor" } }
      ]}}
  ]}
  ```

For **note_collaborators**, let a note's owner manage shares. This needs **four**
actions — `insert`, `select`, `update`, and `delete`:

- Check columns `note_id`, `user_id`, and `role` for `insert`, `select`, **and**
  `update`. The `update` permission on `role` is easy to miss but required: the
  `share` command below upserts with `on_conflict: { update_columns: [role] }`,
  and without it you hit the opaque
  `expected one of the values ['_PLACEHOLDER'] for type
  'note_collaborators_update_column'`.
- Use `{ "note": { "user_id": { "_eq": "X-Hasura-User-Id" } } }` as the `insert`
  check and the `select` / `update` / `delete` filter.

Add the command (the owner shares by the collaborator's user id, defaulting to
`viewer`):

```rust title="src/main.rs"
async fn share(client: &Nhost, note_id: &str, user_id: &str, role: &str) -> Result<()> {
    gql(
        client,
        "mutation Share($noteId: uuid!, $userId: uuid!, $role: String!) {
            insert_note_collaborators_one(
                object: {note_id: $noteId, user_id: $userId, role: $role}
                on_conflict: {constraint: note_collaborators_pkey, update_columns: [role]}
            ) { note_id role }
        }",
        json!({ "noteId": note_id, "userId": user_id, "role": role }),
    )
    .await?;
    println!("shared {} with {} as {}", note_id, user_id, role);
    Ok(())
}

async fn unshare(client: &Nhost, note_id: &str, user_id: &str) -> Result<()> {
    gql(
        client,
        "mutation Unshare($noteId: uuid!, $userId: uuid!) {
            delete_note_collaborators_by_pk(note_id: $noteId, user_id: $userId) { note_id }
        }",
        json!({ "noteId": note_id, "userId": user_id }),
    )
    .await?;
    println!("unshared {} from {}", note_id, user_id);
    Ok(())
}
```

Add both variants to the `Command` enum — `share` takes an optional `role` that
defaults to `viewer`:

```rust title="src/main.rs"
    /// Share a note with another user
    Share {
        note_id: String,
        user_id: String,
        /// viewer (default) or editor
        role: Option<String>,
    },
    /// Remove a collaborator from a note
    Unshare { note_id: String, user_id: String },
```

and wire them into `run`. `unshare` deletes the collaborator row, which the
owner's `delete` permission on `note_collaborators` already allows:

```rust title="src/main.rs"
        Command::Share {
            note_id,
            user_id,
            role,
        } => {
            share(
                &client,
                &note_id,
                &user_id,
                role.as_deref().unwrap_or("viewer"),
            )
            .await
        }
        Command::Unshare { note_id, user_id } => unshare(&client, &note_id, &user_id).await,
```

`export` is the one step that needs the function actually *running* — every part
until now used only the dashboard and the CLI. Your local backend serves the
`functions/` directory automatically: as long as `nhost up` is running,
`functions/notes/export.ts` is live at
`https://local.functions.local.nhost.run/v1/notes/export`. Save the file and the
local runtime hot-reloads it — there's no deploy step.

## The export function

Serverless functions run on your backend. Create `functions/notes/export.ts` in
the `functions/` directory that `nhost init` scaffolded in Part 1 — file-based
routing maps it to `/v1/notes/export` (see the
[Functions docs](/products/functions)). It reads the caller's notes over
GraphQL, renders Markdown, and uploads the result to Storage — **forwarding the
caller's token**, so Hasura permissions and Storage rules apply exactly as they
do in the CLI:

```typescript title="functions/notes/export.ts"
import type { Request, Response } from "express";
import { createClient } from "@nhost/nhost-js";

const nhost = createClient({
  region: process.env.NHOST_REGION,
  subdomain: process.env.NHOST_SUBDOMAIN,
});

export default async (req: Request, res: Response) => {
  const authorization = req.headers.authorization ?? "";
  if (!authorization) {
    return res.status(401).json({ error: "Missing Authorization header" });
  }

  const { body } = await nhost.graphql.request<{ notes: { title: string; content: string }[] }>(
    { query: `query { notes(order_by: {updated_at: desc}) { title content } }` },
    { headers: { Authorization: authorization } },
  );

  const notes = body.data?.notes ?? [];
  const document =
    `# Notes export\n\n_${notes.length} note(s)_\n\n` +
    notes.map((n) => `# ${n.title || "Untitled"}\n\n${n.content}`).join("\n\n---\n\n");

  const fileName = `export-${Date.now()}.md`;
  const upload = await nhost.storage.uploadFiles(
    { "bucket-id": "notes", "file[]": [new File([document], fileName, { type: "text/markdown" })] },
    { headers: { Authorization: authorization } },
  );

  const file = upload.body.processedFiles?.[0];
  res.status(200).json({ fileId: file?.id, fileName, noteCount: notes.length });
};
```

The function imports `@nhost/nhost-js`, and the functions runtime bundles each
function with esbuild against the `functions/` project's own dependencies — so
install the SDK there (the `functions/` directory `nhost init` scaffolded in
Part 1) or the build fails with `Could not resolve "@nhost/nhost-js"`. Pin the
v5 prerelease that `export.ts` targets — npm's `latest` is still the v4 line,
which lacks the `createClient` API the function uses:

```bash Terminal
cd functions
npm install @nhost/nhost-js@5.0.0-beta11
```

## Call it from the CLI

`functions.post` sends an authenticated `POST` — the SDK attaches your token, so
the function receives it in the `Authorization` header:

```rust title="src/main.rs"
async fn export(client: &Nhost) -> Result<()> {
    let export: Value = client.functions.post("/notes/export", &json!({})).await?;
    println!("{}", serde_json::to_string_pretty(&export)?);
    Ok(())
}
```

Add an `Export` variant to the enum (`/// Export your notes via a serverless
function`) and its arm `Command::Export => export(&client).await,` to `run`.

## The complete `src/main.rs`

Here's the whole `src/main.rs` after Part 5 — the finished CLI. Collapsed sections
are unchanged from earlier parts; highlighted lines are what this part added.
Press **Copy** to grab the entire file.

```rust title="src/main.rs"
use std::path::PathBuf;

use clap::{Parser, Subcommand};
use nhost::auth::{SignInEmailPasswordRequest, SignOutRequest, SignUpEmailPasswordRequest};
use nhost::session::FileStorage;
use nhost::storage::{UploadFileMetadata, UploadFilesBody};
use nhost::Nhost;
use serde_json::{json, Value};

const BUCKET: &str = "notes";

type Result<T> = std::result::Result<T, Box<dyn std::error::Error>>;

/// A note-taking CLI built on Nhost.
#[derive(Parser)]
#[command(name = "notes-cli", version, about)]
struct Cli {
    #[command(subcommand)]
    command: Command,
}

// clap derives each subcommand name from the variant in kebab-case, so
// `New` becomes `new`, `Ls` becomes `ls`, and so on.
#[derive(Subcommand)]
enum Command {
    /// Create an account (and sign in if email verification is off)
    Signup { email: String, password: String },
    /// Sign in with email and password
    Login { email: String, password: String },
    /// Sign out and clear the saved session
    Logout,
    /// Show the currently signed-in user
    Whoami,
    /// Create a note
    New {
        title: String,
        content: Option<String>,
    },
    /// List your notes
    Ls,
    /// Pin a note
    Pin { id: String },
    /// Archive a note
    Archive { id: String },
    /// Tag a note (creates the tag if needed)
    Tag { note_id: String, tag_name: String },
    /// Upload a file and attach it to a note
    Attach { note_id: String, file: String },
    /// Download a file by id
    Download { file_id: String, out_path: String },
    /// Share a note with another user
    Share {
        note_id: String,
        user_id: String,
        /// viewer (default) or editor
        role: Option<String>,
    },
    /// Remove a collaborator from a note
    Unshare { note_id: String, user_id: String },
    /// Export your notes via a serverless function
    Export,
}

#[tokio::main]
async fn main() {
    let cli = Cli::parse();
    if let Err(e) = run(cli.command).await {
        eprintln!("error: {e}");
        std::process::exit(1);
    }
}

async fn run(command: Command) -> Result<()> {
    let client = make_client();
    match command {
        Command::Signup { email, password } => signup(&client, &email, &password).await,
        Command::Login { email, password } => login(&client, &email, &password).await,
        Command::Logout => logout(&client).await,
        Command::Whoami => whoami(&client),
        Command::New { title, content } => note_new(&client, &title, content.as_deref()).await,
        Command::Ls => note_ls(&client).await,
        Command::Pin { id } => note_set(&client, &id, json!({ "is_pinned": true })).await,
        Command::Archive { id } => note_set(&client, &id, json!({ "is_archived": true })).await,
        Command::Tag { note_id, tag_name } => note_tag(&client, &note_id, &tag_name).await,
        Command::Attach { note_id, file } => attach(&client, &note_id, &file).await,
        Command::Download { file_id, out_path } => download(&client, &file_id, &out_path).await,
        Command::Share {
            note_id,
            user_id,
            role,
        } => {
            share(
                &client,
                &note_id,
                &user_id,
                role.as_deref().unwrap_or("viewer"),
            )
            .await
        }
        Command::Unshare { note_id, user_id } => unshare(&client, &note_id, &user_id).await,
        Command::Export => export(&client).await,
    }
}

fn make_client() -> Nhost {
    let path = session_path();
    if let Some(parent) = path.parent() {
        let _ = std::fs::create_dir_all(parent);
    }
    Nhost::builder()
        .subdomain(env("NHOST_SUBDOMAIN", "local"))
        .region(env("NHOST_REGION", "local"))
        .storage(Box::new(FileStorage::new(path)))
        .build()
        .expect("client-side build cannot fail")
}

fn session_path() -> PathBuf {
    if let Ok(p) = std::env::var("NHOST_NOTES_SESSION") {
        return PathBuf::from(p);
    }
    let base = std::env::var("XDG_CONFIG_HOME")
        .map(PathBuf::from)
        .unwrap_or_else(|_| {
            PathBuf::from(std::env::var("HOME").unwrap_or_default()).join(".config")
        });
    base.join("nhost-notes").join("session.json")
}

fn env(key: &str, fallback: &str) -> String {
    std::env::var(key).unwrap_or_else(|_| fallback.to_string())
}

async fn signup(client: &Nhost, email: &str, password: &str) -> Result<()> {
    client
        .auth
        .sign_up_email_password(SignUpEmailPasswordRequest {
            email: email.to_string(),
            password: password.to_string(),
            options: None,
            code_challenge: None,
        })
        .await?;
    if client.session()?.is_some() {
        println!("signed up and logged in as {email}");
    } else {
        println!("signed up; verify your email, then `login`");
    }
    Ok(())
}

async fn login(client: &Nhost, email: &str, password: &str) -> Result<()> {
    client
        .auth
        .sign_in_email_password(SignInEmailPasswordRequest {
            email: email.to_string(),
            password: password.to_string(),
        })
        .await?;
    println!("logged in as {email}");
    Ok(())
}

async fn logout(client: &Nhost) -> Result<()> {
    if let Some(sess) = client.session()? {
        let _ = client
            .auth
            .sign_out(SignOutRequest {
                refresh_token: Some(sess.session.refresh_token),
                all: None,
            })
            .await;
    }
    client.clear_session()?;
    println!("logged out");
    Ok(())
}

fn whoami(client: &Nhost) -> Result<()> {
    match client.session()?.and_then(|s| s.session.user) {
        Some(u) => {
            println!("{} ({})", u.email.unwrap_or_default(), u.id);
            Ok(())
        }
        None => Err("not logged in".into()),
    }
}

async fn gql(client: &Nhost, query: &str, vars: Value) -> Result<Value> {
    Ok(client.graphql.query(query).variables(vars).send().await?)
}

fn s(v: &Value, key: &str) -> String {
    v.get(key).and_then(Value::as_str).unwrap_or("").to_string()
}

async fn note_new(client: &Nhost, title: &str, content: Option<&str>) -> Result<()> {
    let obj = json!({ "title": title, "content": content.unwrap_or_default() });
    let data = gql(
        client,
        "mutation NewNote($obj: notes_insert_input!) { insert_notes_one(object: $obj) { id } }",
        json!({ "obj": obj }),
    )
    .await?;
    println!("created {}", s(&data["insert_notes_one"], "id"));
    Ok(())
}

async fn note_ls(client: &Nhost) -> Result<()> {
    let data = gql(
        client,
        "query {
            notes(order_by: [{is_pinned: desc}, {updated_at: desc}]) {
                id title is_pinned
            }
        }",
        Value::Null,
    )
    .await?;
    let notes = data["notes"].as_array().cloned().unwrap_or_default();
    if notes.is_empty() {
        println!("(no notes)");
        return Ok(());
    }
    for n in &notes {
        let pin = if n["is_pinned"].as_bool().unwrap_or(false) {
            "*"
        } else {
            " "
        };
        println!("{pin} {}  {}", s(n, "id"), s(n, "title"));
    }
    Ok(())
}

async fn note_set(client: &Nhost, id: &str, set: Value) -> Result<()> {
    let data = gql(
        client,
        "mutation UpdateNote($id: uuid!, $set: notes_set_input!) {
            update_notes_by_pk(pk_columns: {id: $id}, _set: $set) { id }
        }",
        json!({ "id": id, "set": set }),
    )
    .await?;
    if data["update_notes_by_pk"].is_null() {
        return Err("note not found or not permitted".into());
    }
    println!("updated {}", id);
    Ok(())
}

async fn upsert_tag(client: &Nhost, name: &str) -> Result<String> {
    let data = gql(
        client,
        "mutation UpsertTag($name: String!) {
            insert_tags_one(
                object: {name: $name}
                on_conflict: {constraint: tags_user_id_name_key, update_columns: [name]}
            ) { id }
        }",
        json!({ "name": name }),
    )
    .await?;
    let id = s(&data["insert_tags_one"], "id");
    if id.is_empty() {
        return Err("could not create tag".into());
    }
    Ok(id)
}

async fn note_tag(client: &Nhost, note_id: &str, tag_name: &str) -> Result<()> {
    let tag_id = upsert_tag(client, tag_name).await?;
    gql(
        client,
        "mutation TagNote($noteId: uuid!, $tagId: uuid!) {
            insert_note_tags_one(
                object: {note_id: $noteId, tag_id: $tagId}
                on_conflict: {constraint: note_tags_pkey, update_columns: []}
            ) { note_id }
        }",
        json!({ "noteId": note_id, "tagId": tag_id }),
    )
    .await?;
    println!("tagged {} with #{}", note_id, tag_name);
    Ok(())
}

async fn attach(client: &Nhost, note_id: &str, file: &str) -> Result<()> {
    let bytes = std::fs::read(file)?;
    let name = PathBuf::from(file)
        .file_name()
        .map(|n| n.to_string_lossy().into_owned())
        .unwrap_or_else(|| "file".to_string());

    let up = client
        .storage
        .upload_files(UploadFilesBody {
            bucket_id: Some(BUCKET.to_string()),
            metadata: Some(vec![UploadFileMetadata {
                id: None,
                name: Some(name.clone()),
                metadata: None,
            }]),
            file: vec![bytes],
        })
        .await?;
    let file_id = up
        .body
        .processed_files
        .first()
        .ok_or("upload failed")?
        .id
        .clone();

    gql(
        client,
        "mutation Attach($noteId: uuid!, $fileId: uuid!) {
            insert_note_attachments_one(object: {note_id: $noteId, file_id: $fileId}) { file_id }
        }",
        json!({ "noteId": note_id, "fileId": file_id }),
    )
    .await?;
    println!("attached {} (file {}) to {}", name, file_id, note_id);
    Ok(())
}

async fn download(client: &Nhost, file_id: &str, out_path: &str) -> Result<()> {
    let resp = client.storage.get_file(file_id, None).await?;
    std::fs::write(out_path, &resp.body)?;
    println!("wrote {} bytes to {}", resp.body.len(), out_path);
    Ok(())
}

async fn share(client: &Nhost, note_id: &str, user_id: &str, role: &str) -> Result<()> {
    gql(
        client,
        "mutation Share($noteId: uuid!, $userId: uuid!, $role: String!) {
            insert_note_collaborators_one(
                object: {note_id: $noteId, user_id: $userId, role: $role}
                on_conflict: {constraint: note_collaborators_pkey, update_columns: [role]}
            ) { note_id role }
        }",
        json!({ "noteId": note_id, "userId": user_id, "role": role }),
    )
    .await?;
    println!("shared {} with {} as {}", note_id, user_id, role);
    Ok(())
}

async fn unshare(client: &Nhost, note_id: &str, user_id: &str) -> Result<()> {
    gql(
        client,
        "mutation Unshare($noteId: uuid!, $userId: uuid!) {
            delete_note_collaborators_by_pk(note_id: $noteId, user_id: $userId) { note_id }
        }",
        json!({ "noteId": note_id, "userId": user_id }),
    )
    .await?;
    println!("unshared {} from {}", note_id, user_id);
    Ok(())
}

async fn export(client: &Nhost) -> Result<()> {
    let export: Value = client.functions.post("/notes/export", &json!({})).await?;
    println!("{}", serde_json::to_string_pretty(&export)?);
    Ok(())
}
```

## Try it

```bash Terminal
# You need a second user to share with. Create one in its own session file so it
# doesn't overwrite yours, then read back its id (<otherUserId> is a UUID, not an
# email):
NHOST_NOTES_SESSION=/tmp/bob.json cargo run -- signup bob@example.com 'not-a-secret'
NHOST_NOTES_SESSION=/tmp/bob.json cargo run -- whoami   # bob@example.com (<otherUserId>)

# back as yourself, share a note with bob (role defaults to viewer if omitted)
cargo run -- share <noteId> <otherUserId> editor

# ...and revoke it
cargo run -- unshare <noteId> <otherUserId>

# export your notes to a Markdown file in Storage
cargo run -- export
# { "fileId": "...", "fileName": "export-1737045.md", "noteCount": 3 }

cargo run -- download <fileId> ./notes.md
```

## What you built

You now have a working notes CLI that exercises every core Nhost product:

- **Auth** with a persisted session that survives between runs
- **GraphQL** CRUD protected by owner-scoped row permissions
- **Storage** for attachments, access-controlled by the same rules
- **Functions** that reuse the caller's identity to combine products server-side

You can extend it with `show`, `edit`/`mv`/`rm`, a `notebook new/ls` group, a
`tag ls/new/add/rm` group, and richer output using the same patterns you've
applied here.
