Now the fun part: the data. In this part you'll create the database schema,
lock it down with **owner-scoped permissions**, and add commands to create,
list, and organise notes — all over GraphQL.

:::note
This is **Part 3** of the [Notes CLI with Nhost and Python](/getting-started/tutorials/python/1-introduction)
series.

## Create the schema

Open the **SQL Editor** (**Database → SQL Editor** in the local Nhost dashboard
at `https://local.dashboard.local.nhost.run`) and
run the following. It creates two tables, `notes` and `tags`, plus a `note_tags`
join table and a trigger that keeps `updated_at` current.

```sql SQL Editor
CREATE OR REPLACE FUNCTION public.set_updated_at()
RETURNS TRIGGER AS $$
BEGIN NEW.updated_at = now(); RETURN NEW; END;
$$ LANGUAGE plpgsql;

CREATE TABLE public.notes (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     uuid NOT NULL REFERENCES auth.users (id) ON DELETE CASCADE,
  title       text NOT NULL DEFAULT '',
  content     text NOT NULL DEFAULT '',
  is_pinned   boolean NOT NULL DEFAULT false,
  is_archived boolean NOT NULL DEFAULT false,
  created_at  timestamptz NOT NULL DEFAULT now(),
  updated_at  timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE public.tags (
  id      uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid NOT NULL REFERENCES auth.users (id) ON DELETE CASCADE,
  name    text NOT NULL,
  color   text NOT NULL DEFAULT '#808080',
  UNIQUE (user_id, name)
);

CREATE TABLE public.note_tags (
  note_id uuid NOT NULL REFERENCES public.notes (id) ON DELETE CASCADE,
  tag_id  uuid NOT NULL REFERENCES public.tags (id) ON DELETE CASCADE,
  PRIMARY KEY (note_id, tag_id)
);

CREATE TRIGGER set_notes_updated_at BEFORE UPDATE ON public.notes
  FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();
```

Make sure **Track this** is enabled for each table so it's exposed over GraphQL.
Then open each table's **Relationships** tab and track the foreign-key
relationships Nhost suggests. The Part 3 queries and permissions reference these
by name, so set them exactly: on `notes`, the array relationship to `note_tags`
as `noteTags` (Nhost suggests `note_tags`, so rename it); on `note_tags`, the object relationship to
`notes` as `note` and the one to `tags` as `tag`. A name mismatch surfaces later
as `"noteTags" does not exist` or `"note" does not exist`.

## Lock it down with permissions

By default a tracked table has no permissions — nobody can read or write it.
Open each table's **Edit Permissions** and grant the `user` role owner-scoped
access. The pattern is the same everywhere: a **column preset** sets `user_id`
from the session, and a **custom check** limits each action to the caller's own
rows. The GraphQL engine applies them to every request, using the user ID in
the caller's access token.

To add a custom check, choose **With custom check** under the action's row
permissions and build the rule. The checks below are written in Hasura's JSON
form: `{ "user_id": { "_eq": "X-Hasura-User-Id" } }` is the rule `user_id`
`_eq` `X-Hasura-User-Id`.

:::note
Track any relationship a permission references **before** you save that
permission. A custom check naming a relationship that isn't tracked yet fails
to save, and the dashboard shows a generic `Error: Unknown error occurred.`
instead of naming the missing relationship.
:::

- **tags** — for `insert`, check `name` and `color` and add a **column preset**
  `user_id = X-Hasura-User-Id`; leave `id` and `user_id` unchecked. For
  `select`, check those same columns **plus `id`** (a mutation that returns
  `{ id }` needs `id` in the select permission). For `update`, check `name` and
  `color` so edits take effect. Use the **custom check**
  `{ "user_id": { "_eq": "X-Hasura-User-Id" } }` for `select` / `update` /
  `delete`.
- **notes** — for `insert`, check `title`, `content`, `is_pinned`,
  `is_archived` and add the `user_id` column preset. For `select`,
  check those columns **plus `id` and `updated_at`** — the list query sorts by
  `updated_at`, and Hasura only lets you `order_by` columns the `select`
  permission exposes. For `update`, check the editable columns (`title`,
  `content`, `is_pinned`, `is_archived`). Use the **custom check**
  `{ "user_id": { "_eq": "X-Hasura-User-Id" } }` for `select` / `update` /
  `delete`.
- **note_tags** — gate it through the parent note. Check columns `note_id` and
  `tag_id` for **both** `insert` and `select` (there's no `user_id` preset — a
  `note_tags` row has no `user_id` column; ownership comes from the parent
  note). Use the custom check
  `{ "note": { "user_id": { "_eq": "X-Hasura-User-Id" } } }` for `insert`,
  `select` and `delete`.

## A GraphQL helper

Every command runs a query or mutation, so add a small helper. `request` raises
on GraphQL errors, and the decoded `data` is a plain dict:

```python title="main.py"
async def gql(nhost: Nhost, query: str, variables: dict[str, Any] | None = None) -> dict[str, Any]:
    resp = await nhost.graphql.request(query, variables=variables)
    return resp.body.data or {}
```

## Create and list notes

`insert_notes_one` and the `notes` query are generated by Hasura from your
schema. Notice we never send `user_id` — the permission preset fills it in.

```python title="main.py"
async def cmd_note_new(nhost: Nhost, title: str, content: str | None) -> None:
    obj: dict[str, Any] = {"title": title, "content": content or ""}
    data = await gql(
        nhost,
        """
        mutation NewNote($obj: notes_insert_input!) {
          insert_notes_one(object: $obj) { id }
        }""",
        {"obj": obj},
    )
    print("created", data["insert_notes_one"]["id"])


async def cmd_note_ls(nhost: Nhost) -> None:
    data = await gql(
        nhost,
        """
        query {
          notes(order_by: [{is_pinned: desc}, {updated_at: desc}]) {
            id title is_pinned
          }
        }""",
    )
    notes = data.get("notes", [])
    if not notes:
        print("(no notes)")
        return
    for n in notes:
        pin = "*" if n["is_pinned"] else " "
        print(f"{pin} {n['id']}  {n['title']}")
```

The `notes` query has no `where user_id` clause — it doesn't need one. The
custom check you configured means the GraphQL engine only ever returns the
caller's rows. It does still list **archived** notes, since the query doesn't filter
`is_archived` — so `archive` looks like it has no effect. Add
`where: {is_archived: {_eq: false}}` to the query to hide them.

## Update, tag, and organise

Updates go through `update_notes_by_pk`. One helper covers pin and archive here,
and edit and move in the full CLI; a null result means the row doesn't exist
*or* isn't yours:

```python title="main.py"
async def update_note(nhost: Nhost, note_id: str, set_: dict[str, Any]) -> None:
    data = await gql(
        nhost,
        """
        mutation UpdateNote($id: uuid!, $set: notes_set_input!) {
          update_notes_by_pk(pk_columns: {id: $id}, _set: $set) { id }
        }""",
        {"id": note_id, "set": set_},
    )
    if not data.get("update_notes_by_pk"):
        raise SystemExit("note not found or not permitted")
    print("updated", note_id)
```

Tags use an **upsert**: `insert_tags_one` with `on_conflict` reuses an existing
tag (unique per `user_id, name`) instead of failing, then `insert_note_tags_one`
links it to the note:

```python title="main.py"
async def upsert_tag(nhost: Nhost, name: str) -> str:
    data = await gql(
        nhost,
        """
        mutation UpsertTag($name: String!) {
          insert_tags_one(
            object: {name: $name}
            on_conflict: {constraint: tags_user_id_name_key, update_columns: [name]}
          ) { id }
        }""",
        {"name": name},
    )
    return str(data["insert_tags_one"]["id"])


async def cmd_note_tag(nhost: Nhost, note_id: str, tag_name: str) -> None:
    tag_id = await upsert_tag(nhost, tag_name)
    await gql(
        nhost,
        """
        mutation TagNote($noteId: uuid!, $tagId: uuid!) {
          insert_note_tags_one(
            object: {note_id: $noteId, tag_id: $tagId}
            on_conflict: {constraint: note_tags_pkey, update_columns: []}
          ) { note_id }
        }""",
        {"noteId": note_id, "tagId": tag_id},
    )
    print(f"tagged {note_id} with #{tag_name}")
```

Now expose these as commands. We keep the UX flat — `new`, `ls`,
`pin`, `archive`, `tag` — so each is just another Typer command
(the full CLI — `show`, `notebook new`, `tag ls`, and `--content` /
`--notebook` flags — follows the same pattern). `content` is an optional
positional argument, and `pin` / `archive` share the `update_note`
helper:

```python title="main.py"
@app.command("new")
def note_new(title: str, content: str | None = typer.Argument(None)) -> None:
    """Create a note."""
    run(lambda nhost: cmd_note_new(nhost, title, content))


@app.command("ls")
def note_ls() -> None:
    """List your notes."""
    run(cmd_note_ls)


@app.command("pin")
def note_pin(id: str) -> None:
    """Pin a note."""
    run(lambda nhost: update_note(nhost, id, {"is_pinned": True}))


@app.command("archive")
def note_archive(id: str) -> None:
    """Archive a note."""
    run(lambda nhost: update_note(nhost, id, {"is_archived": True}))


@app.command("tag")
def note_tag(note_id: str, tag_name: str) -> None:
    """Tag a note (creates the tag if needed)."""
    run(lambda nhost: cmd_note_tag(nhost, note_id, tag_name))
```

## The complete `main.py`

Here's the whole `main.py` after Part 3. Collapsed sections are unchanged from
earlier parts; highlighted lines are what this part added. Press **Copy** to grab
the entire file.

```python title="main.py" collapse={1-5,7-51,57-88,166-200,231-236} {6-6,52-56,89-165,201-230}
import asyncio
import getpass
import os
from collections.abc import Awaitable, Callable
from pathlib import Path
from typing import Any

import typer

from nhost import FileStore, Nhost, NhostError
from nhost.auth import (
    SignInEmailPasswordRequest,
    SignOutRequest,
    SignUpEmailPasswordRequest,
)

app = typer.Typer(
    name="notes-cli",
    help="Nhost notes CLI",
    add_completion=False,
    no_args_is_help=True,
)


def session_path() -> Path:
    override = os.environ.get("NHOST_NOTES_SESSION")
    if override:
        return Path(override)
    base = Path(os.environ.get("XDG_CONFIG_HOME", Path.home() / ".config"))
    return base / "nhost-notes" / "session.json"


def make_client() -> Nhost:
    return Nhost(
        subdomain=os.environ.get("NHOST_SUBDOMAIN", "local"),
        region=os.environ.get("NHOST_REGION", "local"),
        session_store=FileStore(session_path()),
    )


def run(coro: Callable[[Nhost], Awaitable[None]]) -> None:
    async def runner() -> None:
        async with make_client() as nhost:
            try:
                await coro(nhost)
            except NhostError as exc:
                raise SystemExit(f"error: {exc}") from exc

    asyncio.run(runner())


async def gql(nhost: Nhost, query: str, variables: dict[str, Any] | None = None) -> dict[str, Any]:
    resp = await nhost.graphql.request(query, variables=variables)
    return resp.body.data or {}


async def cmd_signup(nhost: Nhost, email: str, password: str) -> None:
    response = await nhost.auth.sign_up_email_password(
        body=SignUpEmailPasswordRequest(email=email, password=password)
    )
    # Check this response, not the store: it may still hold someone else's
    # session, and sign-up returns none until the email is verified.
    if response.body.session is not None:
        print("signed up and logged in as", email)
    else:
        print("signed up; verify your email, then `login`")


async def cmd_login(nhost: Nhost, email: str, password: str) -> None:
    await nhost.auth.sign_in_email_password(
        body=SignInEmailPasswordRequest(email=email, password=password)
    )
    print("logged in as", email)


async def cmd_logout(nhost: Nhost) -> None:
    session = await nhost.get_session()
    if session is not None:
        await nhost.auth.sign_out(body=SignOutRequest(refresh_token=session.refresh_token))
    await nhost.clear_session()
    print("logged out")


async def cmd_whoami(nhost: Nhost) -> None:
    session = await nhost.get_session()
    if session is None or session.user is None:
        raise SystemExit("not logged in")
    print(f"{session.user.email} ({session.user.id})")


async def cmd_note_new(nhost: Nhost, title: str, content: str | None) -> None:
    obj: dict[str, Any] = {"title": title, "content": content or ""}
    data = await gql(
        nhost,
        """
        mutation NewNote($obj: notes_insert_input!) {
          insert_notes_one(object: $obj) { id }
        }""",
        {"obj": obj},
    )
    print("created", data["insert_notes_one"]["id"])


async def cmd_note_ls(nhost: Nhost) -> None:
    data = await gql(
        nhost,
        """
        query {

            id title is_pinned
          }

    notes = data.get("notes", [])
    if not notes:
        print("(no notes)")
        return
    for n in notes:
        pin = "*" if n["is_pinned"] else " "
        print(f"{pin} {n['id']}  {n['title']}")


async def update_note(nhost: Nhost, note_id: str, set_: dict[str, Any]) -> None:
    data = await gql(
        nhost,
        """
        mutation UpdateNote($id: uuid!, $set: notes_set_input!) {
          update_notes_by_pk(pk_columns: {id: $id}, _set: $set) { id }
        }""",
        {"id": note_id, "set": set_},
    )
    if not data.get("update_notes_by_pk"):
        raise SystemExit("note not found or not permitted")
    print("updated", note_id)


async def upsert_tag(nhost: Nhost, name: str) -> str:
    data = await gql(
        nhost,
        """
        mutation UpsertTag($name: String!) {
          insert_tags_one(
            object: {name: $name}
            on_conflict: {constraint: tags_user_id_name_key, update_columns: [name]}
          ) { id }
        }""",
        {"name": name},
    )
    return str(data["insert_tags_one"]["id"])


async def cmd_note_tag(nhost: Nhost, note_id: str, tag_name: str) -> None:
    tag_id = await upsert_tag(nhost, tag_name)
    await gql(
        nhost,
        """
        mutation TagNote($noteId: uuid!, $tagId: uuid!) {

            object: {note_id: $noteId, tag_id: $tagId}
            on_conflict: {constraint: note_tags_pkey, update_columns: []}

def read_password() -> str:
    password = os.environ.get("NOTES_PASSWORD")
    if password:
        return password
    return getpass.getpass("Password: ")


@app.command("signup")
def signup(email: str) -> None:
    """Create an account (and sign in if email verification is off)."""
    password = read_password()
    run(lambda nhost: cmd_signup(nhost, email, password))


@app.command("login")
def login(email: str) -> None:
    """Sign in with email and a securely supplied password."""
    password = read_password()
    run(lambda nhost: cmd_login(nhost, email, password))


@app.command("logout")
def logout() -> None:
    """Sign out and clear the saved session."""
    run(cmd_logout)


@app.command("whoami")
def whoami() -> None:
    """Show the currently signed-in user."""
    run(cmd_whoami)


@app.command("new")
def note_new(title: str, content: str | None = typer.Argument(None)) -> None:
    """Create a note."""
    run(lambda nhost: cmd_note_new(nhost, title, content))


@app.command("ls")
def note_ls() -> None:
    """List your notes."""
    run(cmd_note_ls)

def note_pin(id: str) -> None:
    """Pin a note."""
    run(lambda nhost: update_note(nhost, id, {"is_pinned": True}))


@app.command("archive")
def note_archive(id: str) -> None:
    """Archive a note."""
    run(lambda nhost: update_note(nhost, id, {"is_archived": True}))


@app.command("tag")
def note_tag(note_id: str, tag_name: str) -> None:
    """Tag a note (creates the tag if needed)."""
    run(lambda nhost: cmd_note_tag(nhost, note_id, tag_name))


def main() -> None:
    app()


if __name__ == "__main__":
    main()
```

```bash Terminal
python main.py new "Shopping" "buy milk"

```

Sign in as a *different* user and you'll see an empty list — the permissions
guarantee isolation without a single line of filtering in your code.
