Now the fun part: the data. In this part you'll create the database schema,
lock it down with **owner-scoped permissions**, and add commands to create,
list, and organise notes — all over GraphQL.

## Create the schema

Open the **SQL Editor** (**Database → SQL Editor** in the local Nhost dashboard
at `https://local.dashboard.local.nhost.run`) and
run the following. It creates three tables — `notebooks` (folders), `notes`, and `tags` — plus a `note_tags`
join table, and a trigger that keeps `updated_at` current.

```sql SQL Editor
CREATE OR REPLACE FUNCTION public.set_updated_at()
RETURNS TRIGGER AS $$
BEGIN NEW.updated_at = now(); RETURN NEW; END;
$$ LANGUAGE plpgsql;

CREATE TABLE public.notebooks (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id    uuid NOT NULL REFERENCES auth.users (id) ON DELETE CASCADE,
  name       text NOT NULL,
  created_at timestamptz NOT NULL DEFAULT now(),
  updated_at timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE public.notes (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     uuid NOT NULL REFERENCES auth.users (id) ON DELETE CASCADE,
  notebook_id uuid REFERENCES public.notebooks (id) ON DELETE SET NULL,
  title       text NOT NULL DEFAULT '',
  content     text NOT NULL DEFAULT '',
  is_pinned   boolean NOT NULL DEFAULT false,
  is_archived boolean NOT NULL DEFAULT false,
  created_at  timestamptz NOT NULL DEFAULT now(),
  updated_at  timestamptz NOT NULL DEFAULT now()
);

CREATE TABLE public.tags (
  id      uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid NOT NULL REFERENCES auth.users (id) ON DELETE CASCADE,
  name    text NOT NULL,
  color   text NOT NULL DEFAULT '#808080',
  UNIQUE (user_id, name)
);

CREATE TABLE public.note_tags (
  note_id uuid NOT NULL REFERENCES public.notes (id) ON DELETE CASCADE,
  tag_id  uuid NOT NULL REFERENCES public.tags (id) ON DELETE CASCADE,
  PRIMARY KEY (note_id, tag_id)
);

CREATE TRIGGER set_notes_updated_at BEFORE UPDATE ON public.notes
  FOR EACH ROW EXECUTE FUNCTION public.set_updated_at();
```

Make sure **Track this** is enabled for each table so it's exposed over GraphQL.
Then open each table's **Relationships** tab and track the foreign-key
relationships Nhost suggests. The Part 3 queries and permissions reference these
by name, so set them exactly: on `notes`, the object relationship to `notebooks`
as `notebook` and the array relationship to `note_tags` as `noteTags` (Nhost
suggests `note_tags`, so rename it); on `note_tags`, the object relationship to
`notes` as `note` and the one to `tags` as `tag`. A name mismatch surfaces later
as `"noteTags" does not exist` or `"note" does not exist`.

## Lock it down with permissions

By default a tracked table has no permissions — nobody can read or write it.
Open each table's **Edit Permissions** and grant the `user` role owner-scoped
access. The pattern is the same everywhere: writes set `user_id` from the
session, reads and writes are filtered to the caller's own rows.

:::note
Track any relationship a permission references **before** you save that
permission. A filter or check naming a relationship that isn't tracked yet fails
to save, and the dashboard shows a generic `Error: Unknown error occurred.`
instead of naming the missing relationship.
:::

- **notebooks / tags** — for `insert`, check the data columns (`notebooks`:
  `name`; `tags`: `name`, `color`) and add a **column preset**
  `user_id = X-Hasura-User-Id`; leave `id`, `user_id`, `created_at`,
  `updated_at` unchecked. For `select`, check those same data columns **plus
  `id`** (a mutation that returns `{ id }` needs `id` in the select permission).
  For `update`, check the same editable columns (`notebooks`: `name`; `tags`:
  `name`, `color`) so edits take effect. Use the **row filter**
  `{ "user_id": { "_eq": "X-Hasura-User-Id" } }` for `select` / `update` /
  `delete`.
- **notes** — for `insert`, check `title`, `content`, `notebook_id`,
  `is_pinned`, `is_archived` and add the `user_id` column preset. For `select`,
  check those columns **plus `id` and `updated_at`** — the list query sorts by
  `updated_at`, and Hasura only lets you `order_by` columns the `select`
  permission exposes. For `update`, check the editable columns (`title`,
  `content`, `notebook_id`, `is_pinned`, `is_archived`). Use the **row filter**
  `{ "user_id": { "_eq": "X-Hasura-User-Id" } }` for `select` / `update` /
  `delete`. Finally, for `insert` add a **check** that a supplied `notebook_id`
  belongs to the caller so a note can't be filed into someone else's notebook:

  ```json
  { "_or": [
      { "notebook_id": { "_is_null": true } },
      { "notebook": { "user_id": { "_eq": "X-Hasura-User-Id" } } }
  ]}
  ```
- **note_tags** — gate it through the parent note. Check columns `note_id` and
  `tag_id` for **both** `insert` and `select` (there's no `user_id` preset — a
  `note_tags` row has no `user_id` column; ownership comes from the parent
  note). For `insert` use the check
  `{ "note": { "user_id": { "_eq": "X-Hasura-User-Id" } } }`, and the same as
  the `select` / `delete` filter.

:::tip
A row permission can only compare against the *session* user. If you also want
to stop a note being **moved** into another user's notebook on update, enforce
`notebook.user_id = notes.user_id` with a `BEFORE INSERT OR UPDATE` trigger that
verifies the parent notebook's owner matches the note's owner.
:::

## A GraphQL helper

Every command runs a query or mutation, so add a small helper. GraphQL errors
come back as a non-nil `error`, and the decoded `data` is a `map[string]any`:

```go title="main.go"
import "github.com/nhost/nhost/packages/nhost-go/graphql"

func gql(ctx context.Context, c *nhost.Client, query string, vars graphql.Variables) (map[string]any, error) {
	resp, _, err := c.GraphQL.Request(ctx, query, vars, "", nil)
	if err != nil {
		return nil, err
	}
	return resp.Data, nil
}

// tiny helpers for reading the untyped response map
func dig(m map[string]any, keys ...string) any {
	var cur any = m
	for _, k := range keys {
		mm, ok := cur.(map[string]any)
		if !ok {
			return nil
		}
		cur = mm[k]
	}
	return cur
}

func str(v any) string   { s, _ := v.(string); return s }
func asSlice(v any) []any { s, _ := v.([]any); return s }
```

## Create and list notes

`insert_notes_one` and the `notes` query are generated by Hasura from your
schema. Notice we never send `user_id` — the permission preset fills it in.

```go title="main.go"
func noteNew(ctx context.Context, c *nhost.Client, title, content string) error {
	obj := map[string]any{"title": title, "content": content}
	data, err := gql(ctx, c, `
		mutation NewNote($obj: notes_insert_input!) {
			insert_notes_one(object: $obj) { id }
		}`, graphql.Variables{"obj": obj})
	if err != nil {
		return err
	}
	fmt.Println("created", str(dig(data, "insert_notes_one", "id")))
	return nil
}

func noteLs(ctx context.Context, c *nhost.Client) error {
	data, err := gql(ctx, c, `
		query {
			notes(order_by: [{is_pinned: desc}, {updated_at: desc}]) {
				id title is_pinned
			}
		}`, nil)
	if err != nil {
		return err
	}
	notes := asSlice(data["notes"])
	if len(notes) == 0 {
		fmt.Println("(no notes)")
		return nil
	}
	for _, n := range notes {
		m, _ := n.(map[string]any)
		pin := " "
		if b, _ := m["is_pinned"].(bool); b {
			pin = "*"
		}
		fmt.Printf("%s %s  %s\n", pin, str(m["id"]), str(m["title"]))
	}
	return nil
}
```

The `notes` query has no `where user_id` clause — it doesn't need one. The row
filter you configured means the database only ever returns the caller's rows. It
does still list **archived** notes, since the query doesn't filter
`is_archived` — so `archive` looks like it has no effect. Add
`where: {is_archived: {_eq: false}}` to the query to hide them.

## Update, tag, and organise

Updates go through `update_notes_by_pk`. One helper covers edit, pin, archive,
and move; a `nil` primary-key result means the row doesn't exist *or* isn't
yours:

```go title="main.go"
func updateNote(ctx context.Context, c *nhost.Client, id string, set map[string]any) error {
	data, err := gql(ctx, c, `
		mutation UpdateNote($id: uuid!, $set: notes_set_input!) {
			update_notes_by_pk(pk_columns: {id: $id}, _set: $set) { id }
		}`, graphql.Variables{"id": id, "set": set})
	if err != nil {
		return err
	}
	if dig(data, "update_notes_by_pk", "id") == nil {
		return errors.New("note not found or not permitted")
	}
	fmt.Println("updated", id)
	return nil
}
```

Tags use an **upsert**: `insert_tags_one` with `on_conflict` reuses an existing
tag (unique per `user_id, name`) instead of failing, then `insert_note_tags_one`
links it to the note:

```go title="main.go"
func upsertTag(ctx context.Context, c *nhost.Client, name string) (string, error) {
	data, err := gql(ctx, c, `
		mutation UpsertTag($name: String!) {
			insert_tags_one(
				object: {name: $name}
				on_conflict: {constraint: tags_user_id_name_key, update_columns: [name]}
			) { id }
		}`, graphql.Variables{"name": name})
	if err != nil {
		return "", err
	}
	id := str(dig(data, "insert_tags_one", "id"))
	if id == "" {
		return "", errors.New("could not create tag")
	}
	return id, nil
}

func noteTag(ctx context.Context, c *nhost.Client, noteID, tagName string) error {
	tagID, err := upsertTag(ctx, c, tagName)
	if err != nil {
		return err
	}
	_, err = gql(ctx, c, `
		mutation TagNote($noteId: uuid!, $tagId: uuid!) {
			insert_note_tags_one(
				object: {note_id: $noteId, tag_id: $tagId}
				on_conflict: {constraint: note_tags_pkey, update_columns: []}
			) { note_id }
		}`, graphql.Variables{"noteId": noteID, "tagId": tagID})
	if err != nil {
		return err
	}
	fmt.Printf("tagged %s with #%s\n", noteID, tagName)
	return nil
}
```

Now expose these as commands. We keep the UX flat — `new`, `ls`,
`pin`, `archive`, `tag` — so each is just another command added to
the root (the full CLI — `show`, the `notebook new`/`notebook ls` group,
the `tag ls`/`new`/`add`/`rm` group, and `--content`/`--notebook` flags —
follows the same pattern). `pin` and
`archive` share the `updateNote` helper, and `new` takes an optional
positional `CONTENT`:

```go title="main.go"
	root.AddCommand(&cobra.Command{

	root.AddCommand(&cobra.Command{

	root.AddCommand(&cobra.Command{
```

## The complete `main.go`

Here's the whole `main.go` after Part 3. Collapsed sections are unchanged from earlier parts; the highlighted lines are what this part added. Press **Copy** to grab the entire file at once.

```go title="main.go"
import (

	}

// newClient builds the Nhost client. The client middleware attaches the access
// token to every request and refreshes it automatically once we sign in.
func newClient() *nhost.Client {
	return nhost.New(nhost.Options{
		Subdomain: env("NHOST_SUBDOMAIN", "local"),
		Region:    env("NHOST_REGION", "local"),
		Storage:   &session.FileStorage{Path: sessionPath()},
	})
}

func sessionPath() string {
	if p := os.Getenv("NHOST_NOTES_SESSION"); p != "" {
		return p
	}
	dir, err := os.UserConfigDir()
	if err != nil {
		dir = os.TempDir()
	}
	return filepath.Join(dir, "nhost-notes", "session.json")
}

func env(key, fallback string) string {
	if v := os.Getenv(key); v != "" {
		return v
	}
	return fallback
}

func cmdSignup(ctx context.Context, c *nhost.Client, email, password string) error {
	if _, _, err := c.Auth.SignUpEmailPassword(ctx, auth.SignUpEmailPasswordRequest{
		Email:    email,
		Password: password,
	}, nil); err != nil {
		return err
	}
	if _, ok := c.GetUserSession(); ok {
		fmt.Println("signed up and logged in as", email)
	} else {
		fmt.Println("signed up; verify your email, then `login`")
	}
	return nil
}

func cmdLogin(ctx context.Context, c *nhost.Client, email, password string) error {
	if _, _, err := c.Auth.SignInEmailPassword(ctx, auth.SignInEmailPasswordRequest{
		Email:    email,
		Password: password,
	}, nil); err != nil {
		return err
	}
	fmt.Println("logged in as", email)
	return nil
}

func cmdLogout(ctx context.Context, c *nhost.Client) error {
	if s, ok := c.GetUserSession(); ok {
		rt := s.RefreshToken
		_, _, _ = c.Auth.SignOut(ctx, auth.SignOutRequest{RefreshToken: &rt}, nil)
	}
	c.ClearSession()
	fmt.Println("logged out")
	return nil
}

func cmdWhoami(c *nhost.Client) error {
	s, ok := c.GetUserSession()
	if !ok || s.User == nil {
		return errors.New("not logged in")
	}
	email := ""
	if s.User.Email != nil {
		email = *s.User.Email
	}
	fmt.Printf("%s (%s)\n", email, s.User.ID)
	return nil
}
```
