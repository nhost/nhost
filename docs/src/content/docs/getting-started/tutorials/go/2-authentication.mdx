In [Part 1](/getting-started/tutorials/go/1-introduction) you scaffolded the CLI
and wired up the Nhost client. A command-line tool runs, exits, and runs again —
so to stay signed in between invocations we need to **persist the session to
disk**. The Go SDK makes this a one-liner.

:::note
This is **Part 2** of the [Notes CLI with Nhost and Go](/getting-started/tutorials/go/1-introduction)
series.
:::

## Persist the session

The client accepts a `Storage` backend that it uses to save and load the
session. The SDK ships `session.FileStorage`, which writes the session to a JSON
file with `0600` permissions. Update `newClient` to use it:

```go title="main.go"
import (
	// ...existing imports...
	"path/filepath"

	"github.com/nhost/nhost/packages/nhost-go/session"
)

func newClient() *nhost.Client {
	return nhost.New(nhost.Options{
		Subdomain: env("NHOST_SUBDOMAIN", "local"),
		Region:    env("NHOST_REGION", "local"),
		Storage:   &session.FileStorage{Path: sessionPath()},
	})
}

// sessionPath is where the signed-in session is cached between runs.
func sessionPath() string {
	if p := os.Getenv("NHOST_NOTES_SESSION"); p != "" {
		return p
	}
	dir, err := os.UserConfigDir()
	if err != nil {
		dir = os.TempDir()
	}
	return filepath.Join(dir, "nhost-notes", "session.json")
}
```

With a `Storage` backend configured, the SDK's middleware does the rest: after
you sign in it saves the session, attaches the access token to every request,
and refreshes the token in the background when it expires. Your commands never
touch tokens directly.

## Add the auth commands

`whoami` already exists from Part 1. Add the three sign-in commands.
`SignInEmailPassword`, `SignUpEmailPassword`, and `SignOut` come from the `auth`
package. cobra parses each command's positional arguments for us, so there's no
manual argument-count checking to write:

```go title="main.go"
import "github.com/nhost/nhost/packages/nhost-go/auth"

func cmdSignup(ctx context.Context, c *nhost.Client, email, password string) error {
	if _, _, err := c.Auth.SignUpEmailPassword(ctx, auth.SignUpEmailPasswordRequest{
		Email:    email,
		Password: password,
	}, nil); err != nil {
		return err
	}
	if _, ok := c.GetUserSession(); ok {
		fmt.Println("signed up and logged in as", email)
	} else {
		fmt.Println("signed up; verify your email, then `login`")
	}
	return nil
}

func cmdLogin(ctx context.Context, c *nhost.Client, email, password string) error {
	if _, _, err := c.Auth.SignInEmailPassword(ctx, auth.SignInEmailPasswordRequest{
		Email:    email,
		Password: password,
	}, nil); err != nil {
		return err
	}
	fmt.Println("logged in as", email)
	return nil
}

func cmdLogout(ctx context.Context, c *nhost.Client) error {
	if s, ok := c.GetUserSession(); ok {
		rt := s.RefreshToken
		_, _, _ = c.Auth.SignOut(ctx, auth.SignOutRequest{RefreshToken: &rt}, nil)
	}
	c.ClearSession()
	fmt.Println("logged out")
	return nil
}
```

`GetUserSession` reads the current session from storage without a network call —
perfect for `whoami`. `ClearSession` removes the cached file (a client-side sign
out), while `SignOut` revokes the refresh token on the server.

Now register the three commands on the root command in `rootCmd`, alongside the
`whoami` command from Part 1. Because the auth handlers need a context, capture
one at the top of `rootCmd` (`ctx := context.Background()`) and pass it in:

```go title="main.go"
	root.AddCommand(&cobra.Command{
		Use:   "signup EMAIL PASSWORD",
		Short: "Create an account (and sign in if email verification is off)",
		Args:  cobra.ExactArgs(2),
		RunE: func(_ *cobra.Command, args []string) error {
			return cmdSignup(ctx, client, args[0], args[1])
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "login EMAIL PASSWORD",
		Short: "Sign in with email and password",
		Args:  cobra.ExactArgs(2),
		RunE: func(_ *cobra.Command, args []string) error {
			return cmdLogin(ctx, client, args[0], args[1])
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "logout",
		Short: "Sign out and clear the saved session",
		Args:  cobra.NoArgs,
		RunE: func(_ *cobra.Command, _ []string) error {
			return cmdLogout(ctx, client)
		},
	})
```

## Enable email/password sign-up

New projects require email verification by default. For a smooth CLI experience
during development, you can allow users to sign in immediately after sign-up: in
the local Nhost dashboard (`https://local.dashboard.local.nhost.run`) open
**Settings → Sign-In methods** and, under **Email and Password**, disable
*"Require verified emails"*. (Locally, verification emails are caught by Mailhog
at `https://local.mailhog.local.nhost.run` if you'd rather click the link
instead.)

## The complete `main.go`

Here's the whole `main.go` after Part 2. Collapsed sections are unchanged from Part 1; the highlighted lines are what this part added. Press **Copy** to grab the entire file at once.

```go title="main.go"
package main

import (
	"context"
	"errors"
	"fmt"
	"os"
	"path/filepath"

	"github.com/spf13/cobra"

	nhost "github.com/nhost/nhost/packages/nhost-go"
	"github.com/nhost/nhost/packages/nhost-go/auth"
	"github.com/nhost/nhost/packages/nhost-go/session"
)

// client is built once in the root command's PersistentPreRun and reused by
// every subcommand.
var client *nhost.Client

func main() {
	if err := rootCmd().Execute(); err != nil {
		fmt.Fprintln(os.Stderr, "error:", err)
		os.Exit(1)
	}
}

func rootCmd() *cobra.Command {
	root := &cobra.Command{
		Use:           "notes-cli",
		Short:         "A note-taking CLI built on Nhost",
		SilenceUsage:  true,
		SilenceErrors: true,
		PersistentPreRun: func(_ *cobra.Command, _ []string) {
			client = newClient()
		},
	}

	ctx := context.Background()

	root.AddCommand(&cobra.Command{
		Use:   "signup EMAIL PASSWORD",
		Short: "Create an account (and sign in if email verification is off)",
		Args:  cobra.ExactArgs(2),
		RunE: func(_ *cobra.Command, args []string) error {
			return cmdSignup(ctx, client, args[0], args[1])
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "login EMAIL PASSWORD",
		Short: "Sign in with email and password",
		Args:  cobra.ExactArgs(2),
		RunE: func(_ *cobra.Command, args []string) error {
			return cmdLogin(ctx, client, args[0], args[1])
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "logout",
		Short: "Sign out and clear the saved session",
		Args:  cobra.NoArgs,
		RunE: func(_ *cobra.Command, _ []string) error {
			return cmdLogout(ctx, client)
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "whoami",
		Short: "Show the currently signed-in user",
		Args:  cobra.NoArgs,
		RunE: func(_ *cobra.Command, _ []string) error {
			return cmdWhoami(client)
		},
	})

	return root
}

// newClient builds the Nhost client. The client middleware attaches the access
// token to every request and refreshes it automatically once we sign in.
func newClient() *nhost.Client {
	return nhost.New(nhost.Options{
		Subdomain: env("NHOST_SUBDOMAIN", "local"),
		Region:    env("NHOST_REGION", "local"),
		Storage:   &session.FileStorage{Path: sessionPath()},
	})
}

func sessionPath() string {
	if p := os.Getenv("NHOST_NOTES_SESSION"); p != "" {
		return p
	}
	dir, err := os.UserConfigDir()
	if err != nil {
		dir = os.TempDir()
	}
	return filepath.Join(dir, "nhost-notes", "session.json")
}

func env(key, fallback string) string {
	if v := os.Getenv(key); v != "" {
		return v
	}
	return fallback
}

func cmdSignup(ctx context.Context, c *nhost.Client, email, password string) error {
	if _, _, err := c.Auth.SignUpEmailPassword(ctx, auth.SignUpEmailPasswordRequest{
		Email:    email,
		Password: password,
	}, nil); err != nil {
		return err
	}
	if _, ok := c.GetUserSession(); ok {
		fmt.Println("signed up and logged in as", email)
	} else {
		fmt.Println("signed up; verify your email, then `login`")
	}
	return nil
}

func cmdLogin(ctx context.Context, c *nhost.Client, email, password string) error {
	if _, _, err := c.Auth.SignInEmailPassword(ctx, auth.SignInEmailPasswordRequest{
		Email:    email,
		Password: password,
	}, nil); err != nil {
		return err
	}
	fmt.Println("logged in as", email)
	return nil
}

func cmdLogout(ctx context.Context, c *nhost.Client) error {
	if s, ok := c.GetUserSession(); ok {
		rt := s.RefreshToken
		_, _, _ = c.Auth.SignOut(ctx, auth.SignOutRequest{RefreshToken: &rt}, nil)
	}
	c.ClearSession()
	fmt.Println("logged out")
	return nil
}

func cmdWhoami(c *nhost.Client) error {
	s, ok := c.GetUserSession()
	if !ok || s.User == nil {
		return errors.New("not logged in")
	}
	email := ""
	if s.User.Email != nil {
		email = *s.User.Email
	}
	fmt.Printf("%s (%s)\n", email, s.User.ID)
	return nil
}
```

:::caution
Do the **Enable email/password sign-up** step above before running `signup`. If
*"Require verified emails"* is still on, `signup` lands in the verify-email
branch and prints `signed up; verify your email, then login` instead of an
active session — so `whoami` reports `not logged in` until you verify.
:::

## Try it

```bash Terminal
go run . signup ada@example.com 'not-a-secret'
go run . whoami
# ada@example.com (a1b2c3d4-...)

go run . logout
go run . whoami
# error: not logged in

go run . login ada@example.com 'not-a-secret'
```

The session path comes from `os.UserConfigDir()`, so it's platform-specific: on
macOS it's `~/Library/Application Support/nhost-notes/session.json`, on Linux
`~/.config/nhost-notes/session.json`, and on Windows
`%AppData%\nhost-notes\session.json`. Delete that file (or run `logout`) to sign
out.
