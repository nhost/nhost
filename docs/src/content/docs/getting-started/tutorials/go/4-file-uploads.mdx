Notes are more useful with files attached. In this part you'll upload a file to
**Nhost Storage**, record the link in the database, and download it again.

:::note
This is **Part 4** of the [Notes CLI with Nhost and Go](/getting-started/tutorials/go/1-introduction)
series.
:::

## Add a bucket and a join table

Run this in the **SQL Editor**. It creates a `notes` storage bucket and a
`note_attachments` table that links a note to an uploaded file (Nhost's Storage
metadata lives in the tracked `storage.files` table).

```sql SQL Editor
INSERT INTO storage.buckets (id) VALUES ('notes') ON CONFLICT DO NOTHING;

CREATE TABLE public.note_attachments (
  note_id uuid NOT NULL REFERENCES public.notes (id) ON DELETE CASCADE,
  file_id uuid NOT NULL REFERENCES storage.files (id) ON DELETE CASCADE,
  PRIMARY KEY (note_id, file_id)
);
```

Track `note_attachments`, then open its **Relationships** tab and add the two
foreign-key relationships Nhost suggests: `file`
(`public.note_attachments.file_id → storage.files.id`) and `note`
(`public.note_attachments.note_id → public.notes.id`). Then set permissions for
the `user` role:

- **note_attachments** — gate through the parent note. Check columns `note_id`
  and `file_id` for both `insert` and `select` (without them the insert
  permission allows zero columns and `attach` is rejected), then use
  `{ "note": { "user_id": { "_eq": "X-Hasura-User-Id" } } }` as the `insert`
  check and the `select` / `delete` filter.
- **storage.files** — set these under **Storage → Permissions** (Nhost's UI for
  the `storage.files` table permissions), where **Upload** is the `insert`
  permission and **Download** is the `select` permission. Leave Replace / Delete
  as-is for this tutorial.
  - **Upload** — allow it for `user` and enable *Prefill
    `uploaded_by_user_id` with `X-Hasura-User-Id`* so every upload is stamped
    with its uploader. Without this stamp the column stays `NULL`, the Download
    filter below never matches, and `download` 404s with `file not found` even
    though `attach` succeeded.
  - **Download** — a user should see a file if they uploaded it **or** it's
    attached to a note they can see. This clause traverses a `noteAttachments`
    array relationship on `storage.files`, which lives in the **Database** UI —
    so add it there **first** under **Database → `storage` schema → `files` →
    Relationships**, otherwise the row filter won't save
    (`"noteAttachments" does not exist`). Then, back in **Storage → Permissions**
    for the Download action, filter on the **database column**
    `uploaded_by_user_id` (the `uploadedByUserId` GraphQL alias errors on save
    with `"uploadedByUserId" does not exist`):

    ```json
    { "_or": [
        { "uploaded_by_user_id": { "_eq": "X-Hasura-User-Id" } },
        { "noteAttachments": { "note": { "user_id": { "_eq": "X-Hasura-User-Id" } } } }
    ]}
    ```

## Upload a file

`Storage.UploadFiles` takes the bucket, the raw bytes, and per-file metadata. It
returns the processed files, including the new file's `ID`, which we then link to
the note. Add a `bucket` constant for the bucket id you created above:

```go title="main.go"
import "github.com/nhost/nhost/packages/nhost-go/storage"

const bucket = "notes"

func cmdAttach(ctx context.Context, c *nhost.Client, noteID, file string) error {
	raw, err := os.ReadFile(file)
	if err != nil {
		return err
	}
	name := filepath.Base(file)
	b := bucket
	up, _, err := c.Storage.UploadFiles(ctx, storage.UploadFilesBody{
		BucketID: &b,
		File:     [][]byte{raw},
		Metadata: &[]storage.UploadFileMetadata{{Name: &name}},
	}, nil)
	if err != nil {
		return err
	}
	if len(up.ProcessedFiles) == 0 {
		return errors.New("upload failed")
	}
	fileID := up.ProcessedFiles[0].ID

	if _, err := gql(ctx, c, `
		mutation Attach($noteId: uuid!, $fileId: uuid!) {
			insert_note_attachments_one(object: {note_id: $noteId, file_id: $fileId}) { file_id }
		}`, graphql.Variables{"noteId": noteID, "fileId": fileID}); err != nil {
		return err
	}
	fmt.Printf("attached %s (file %s) to %s\n", name, fileID, noteID)
	return nil
}
```

## Download a file

`Storage.GetFile` streams the file's bytes back. Write them wherever the user
asked:

```go title="main.go"
func cmdDownload(ctx context.Context, c *nhost.Client, fileID, outPath string) error {
	resp, _, err := c.Storage.GetFile(ctx, fileID, nil, nil)
	if err != nil {
		return err
	}
	if err := os.WriteFile(outPath, resp, 0o600); err != nil {
		return err
	}
	fmt.Printf("wrote %d bytes to %s\n", len(resp), outPath)
	return nil
}
```

Register both as top-level commands in `rootCmd`:

```go title="main.go"
	root.AddCommand(&cobra.Command{
		Use:   "attach NOTE_ID FILE",
		Short: "Upload a file and attach it to a note",
		Args:  cobra.ExactArgs(2),
		RunE: func(_ *cobra.Command, args []string) error {
			return cmdAttach(ctx, client, args[0], args[1])
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "download FILE_ID OUT_PATH",
		Short: "Download a file by id",
		Args:  cobra.ExactArgs(2),
		RunE: func(_ *cobra.Command, args []string) error {
			return cmdDownload(ctx, client, args[0], args[1])
		},
	})
```

## The complete `main.go`

Here's the whole `main.go` after Part 4. Collapsed sections are unchanged from earlier parts; the highlighted lines are what this part added. Press **Copy** to grab the entire file at once.

```go title="main.go"
package main

import (
	"context"
	"errors"
	"fmt"
	"os"
	"path/filepath"

	"github.com/spf13/cobra"

	nhost "github.com/nhost/nhost/packages/nhost-go"
	"github.com/nhost/nhost/packages/nhost-go/auth"
	"github.com/nhost/nhost/packages/nhost-go/graphql"
	"github.com/nhost/nhost/packages/nhost-go/session"
	"github.com/nhost/nhost/packages/nhost-go/storage"
)

const bucket = "notes"

// client is built once in the root command's PersistentPreRun and reused by
// every subcommand.
var client *nhost.Client

func main() {
	if err := rootCmd().Execute(); err != nil {
		fmt.Fprintln(os.Stderr, "error:", err)
		os.Exit(1)
	}
}

func rootCmd() *cobra.Command {
	root := &cobra.Command{
		Use:           "notes-cli",
		Short:         "A note-taking CLI built on Nhost",
		SilenceUsage:  true,
		SilenceErrors: true,
		PersistentPreRun: func(_ *cobra.Command, _ []string) {
			client = newClient()
		},
	}

	ctx := context.Background()

	root.AddCommand(&cobra.Command{
		Use:   "signup EMAIL PASSWORD",
		Short: "Create an account (and sign in if email verification is off)",
		Args:  cobra.ExactArgs(2),
		RunE: func(_ *cobra.Command, args []string) error {
			return cmdSignup(ctx, client, args[0], args[1])
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "login EMAIL PASSWORD",
		Short: "Sign in with email and password",
		Args:  cobra.ExactArgs(2),
		RunE: func(_ *cobra.Command, args []string) error {
			return cmdLogin(ctx, client, args[0], args[1])
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "logout",
		Short: "Sign out and clear the saved session",
		Args:  cobra.NoArgs,
		RunE: func(_ *cobra.Command, _ []string) error {
			return cmdLogout(ctx, client)
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "whoami",
		Short: "Show the currently signed-in user",
		Args:  cobra.NoArgs,
		RunE: func(_ *cobra.Command, _ []string) error {
			return cmdWhoami(client)
		},
	})

	root.AddCommand(&cobra.Command{
		Use:   "new TITLE [CONTENT]",
		Short: "Create a note",
		Args:  cobra.RangeArgs(1, 2),
		RunE: func(_ *cobra.Command, args []string) error {
			content := ""
			if len(args) > 1 {
				content = args[1]
			}
			return noteNew(ctx, client, args[0], content)
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "ls",
		Short: "List your notes",
		Args:  cobra.NoArgs,
		RunE: func(_ *cobra.Command, _ []string) error {
			return noteLs(ctx, client)
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "pin ID",
		Short: "Pin a note",
		Args:  cobra.ExactArgs(1),
		RunE: func(_ *cobra.Command, args []string) error {
			return updateNote(ctx, client, args[0], map[string]any{"is_pinned": true})
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "archive ID",
		Short: "Archive a note",
		Args:  cobra.ExactArgs(1),
		RunE: func(_ *cobra.Command, args []string) error {
			return updateNote(ctx, client, args[0], map[string]any{"is_archived": true})
		},
	})
	root.AddCommand(&cobra.Command{
		Use:   "tag NOTE_ID TAG_NAME",
		Short: "Tag a note (creates the tag if needed)",
		Args:  cobra.ExactArgs(2),

// newClient builds the Nhost client. The client middleware attaches the access
// token to every request and refreshes it automatically once we sign in.
func newClient() *nhost.Client {
	return nhost.New(nhost.Options{
		Subdomain: env("NHOST_SUBDOMAIN", "local"),
		Region:    env("NHOST_REGION", "local"),
		Storage:   &session.FileStorage{Path: sessionPath()},
	})
}

func sessionPath() string {
	if p := os.Getenv("NHOST_NOTES_SESSION"); p != "" {
		return p
	}
	dir, err := os.UserConfigDir()
	if err != nil {
		dir = os.TempDir()
	}
	return filepath.Join(dir, "nhost-notes", "session.json")
}

func env(key, fallback string) string {
	if v := os.Getenv(key); v != "" {
		return v
	}
	return fallback
}

func gql(ctx context.Context, c *nhost.Client, query string, vars graphql.Variables) (map[string]any, error) {
	resp, _, err := c.GraphQL.Request(ctx, query, vars, "", nil)
	if err != nil {
		return nil, err
	}
	return resp.Data, nil
}

// tiny helpers for reading the untyped response map
func dig(m map[string]any, keys ...string) any {
	var cur any = m
	for _, k := range keys {
		mm, ok := cur.(map[string]any)
		if !ok {
			return nil
		}
		cur = mm[k]
	}
	return cur
}

func str(v any) string    { s, _ := v.(string); return s }
func asSlice(v any) []any { s, _ := v.([]any); return s }

func cmdSignup(ctx context.Context, c *nhost.Client, email, password string) error {
	if _, _, err := c.Auth.SignUpEmailPassword(ctx, auth.SignUpEmailPasswordRequest{
		Email:    email,
		Password: password,
	}, nil); err != nil {
		return err
	}
	if _, ok := c.GetUserSession(); ok {
		fmt.Println("signed up and logged in as", email)
	} else {
		fmt.Println("signed up; verify your email, then `login`")
	}
	return nil
}

func cmdLogin(ctx context.Context, c *nhost.Client, email, password string) error {
	if _, _, err := c.Auth.SignInEmailPassword(ctx, auth.SignInEmailPasswordRequest{
		Email:    email,
		Password: password,
	}, nil); err != nil {
		return err
	}
	fmt.Println("logged in as", email)
	return nil
}

func cmdLogout(ctx context.Context, c *nhost.Client) error {
	if s, ok := c.GetUserSession(); ok {
		rt := s.RefreshToken
		_, _, _ = c.Auth.SignOut(ctx, auth.SignOutRequest{RefreshToken: &rt}, nil)
	}
	c.ClearSession()
	fmt.Println("logged out")
	return nil
}

func cmdWhoami(c *nhost.Client) error {
	s, ok := c.GetUserSession()
	if !ok || s.User == nil {
		return errors.New("not logged in")
	}
	email := ""
	if s.User.Email != nil {
		email = *s.User.Email
	}
	fmt.Printf("%s (%s)\n", email, s.User.ID)
	return nil
}

func noteNew(ctx context.Context, c *nhost.Client, title, content string) error {
	obj := map[string]any{"title": title, "content": content}
	data, err := gql(ctx, c, `
		mutation NewNote($obj: notes_insert_input!) {
			insert_notes_one(object: $obj) { id }
		}`, graphql.Variables{"obj": obj})
	if err != nil {
		return err
	}
	fmt.Println("created", str(dig(data, "insert_notes_one", "id")))
	return nil
}

func noteLs(ctx context.Context, c *nhost.Client) error {
	data, err := gql(ctx, c, `
		query {
			notes(order_by: [{is_pinned: desc}, {updated_at: desc}]) {
				id title is_pinned
			}
		}`, nil)
	if err != nil {
		return err
	}
	notes := asSlice(data["notes"])
	if len(notes) == 0 {
		fmt.Println("(no notes)")
		return nil
	}
	for _, n := range notes {
		m, _ := n.(map[string]any)
		pin := " "
		if b, _ := m["is_pinned"].(bool); b {
			pin = "*"
		}
		fmt.Printf("%s %s  %s\n", pin, str(m["id"]), str(m["title"]))
	}
	return nil
}

func updateNote(ctx context.Context, c *nhost.Client, id string, set map[string]any) error {
	data, err := gql(ctx, c, `
		mutation UpdateNote($id: uuid!, $set: notes_set_input!) {
			update_notes_by_pk(pk_columns: {id: $id}, _set: $set) { id }
		}`, graphql.Variables{"id": id, "set": set})
	if err != nil {
		return err
	}
	if dig(data, "update_notes_by_pk", "id") == nil {
		return errors.New("note not found or not permitted")
	}
	fmt.Println("updated", id)
	return nil
}

func upsertTag(ctx context.Context, c *nhost.Client, name string) (string, error) {
	data, err := gql(ctx, c, `
		mutation UpsertTag($name: String!) {
			insert_tags_one(
				object: {name: $name}
				on_conflict: {constraint: tags_user_id_name_key, update_columns: [name]}
			) { id }
		}`, graphql.Variables{"name": name})
	if err != nil {
		return "", err
	}
	id := str(dig(data, "insert_tags_one", "id"))
	if id == "" {
		return "", errors.New("could not create tag")
	}
	return id, nil
}

func noteTag(ctx context.Context, c *nhost.Client, noteID, tagName string) error {
	tagID, err := upsertTag(ctx, c, tagName)
	if err != nil {
		return err
	}
	_, err = gql(ctx, c, `
		mutation TagNote($noteId: uuid!, $tagId: uuid!) {
			insert_note_tags_one(
				object: {note_id: $noteId, tag_id: $tagId}
				on_conflict: {constraint: note_tags_pkey, update_columns: []}
			) { note_id }
		}`, graphql.Variables{"noteId": noteID, "tagId": tagID})
	if err != nil {
		return err
	}
	fmt.Printf("tagged %s with #%s\n", noteID, tagName)
	return nil
}

func cmdAttach(ctx context.Context, c *nhost.Client, noteID, file string) error {
	raw, err := os.ReadFile(file)
	if err != nil {
		return err
	}
	name := filepath.Base(file)
	b := bucket
	up, _, err := c.Storage.UploadFiles(ctx, storage.UploadFilesBody{
		BucketID: &b,
		File:     [][]byte{raw},
		Metadata: &[]storage.UploadFileMetadata{{Name: &name}},
	}, nil)
	if err != nil {
		return err
	}
	if len(up.ProcessedFiles) == 0 {
		return errors.New("upload failed")
	}
	fileID := up.ProcessedFiles[0].ID

	if _, err := gql(ctx, c, `
		mutation Attach($noteId: uuid!, $fileId: uuid!) {
			insert_note_attachments_one(object: {note_id: $noteId, file_id: $fileId}) { file_id }
		}`, graphql.Variables{"noteId": noteID, "fileId": fileID}); err != nil {
		return err
	}
	fmt.Printf("attached %s (file %s) to %s\n", name, fileID, noteID)
	return nil
}

func cmdDownload(ctx context.Context, c *nhost.Client, fileID, outPath string) error {
	resp, _, err := c.Storage.GetFile(ctx, fileID, nil, nil)
	if err != nil {
		return err
	}
	if err := os.WriteFile(outPath, resp, 0o600); err != nil {
		return err
	}
	fmt.Printf("wrote %d bytes to %s\n", len(resp), outPath)
	return nil
}
```

## Try it

```bash Terminal
go run . new "Design doc"

# attach any file you have on disk — create a quick sample if you need one
echo "notes CLI attachment demo" > diagram.txt
go run . attach <noteId> ./diagram.txt
# attached diagram.txt (file <fileId>) to <noteId>

go run . download <fileId> ./out.txt
# wrote 26 bytes to ./out.txt
```

Because Storage access is governed by the same `storage.files` permissions, a
different user can't download your file even with its ID — the request is denied
by the backend.
