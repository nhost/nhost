The Nhost MCP server can be accessed through any client that supports the Model Context Protocol (MCP).

For CLI-based assistants, register the server with a single command. See [Development Setup](/platform/cli/mcp/development-setup) for the full walkthrough.

## Claude Code

```bash Terminal
claude mcp add nhost nhost mcp start
```

## Codex CLI

```bash Terminal
codex mcp add nhost -- nhost mcp start
```

## Gemini CLI

```bash Terminal
gemini mcp add nhost nhost mcp start
```

## Cursor

1. Go to "Cursor Settings"
2. Click on "MCP"
3. Click on "+ Add new global MCP server"
4. Add the following object inside `"mcpServers"`:

```json
    "mcp-nhost": {
      "command": "nhost",
      "args": [
        "mcp", "start",
      ],
    }
```
