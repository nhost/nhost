Nhost AI stores configuration and conversation data in PostgreSQL tables under the `ai` schema.
The service tracks these tables in your GraphQL API with camel-cased custom root fields. Normal
GraphQL permissions determine which operations and rows each role can access.

The AI service does not expose its own remote GraphQL schema. Agent conversations stream through
[REST endpoints](/products/ai/agents/sessions-and-streaming), while management uses the generated
fields below.

## Agents

| Operation | GraphQL field |
| --- | --- |
| Get one | `aiAgent` |
| List | `aiAgents` |
| Insert one | `insertAiAgent` |
| Update by primary key | `updateAiAgent` |
| Delete by primary key | `deleteAiAgent` |

See [Managing Agents](/products/ai/agents/managing-agents) for operation examples and field details.

## Agent messages

| Operation | GraphQL field |
| --- | --- |
| Get one | `aiAgentMessage` |
| List | `aiAgentMessages` |
| Insert one | `insertAiAgentMessage` |
| Insert many | `insertAiAgentMessages` |
| Update by primary key | `updateAiAgentMessage` |
| Delete by primary key | `deleteAiAgentMessage` |

Applications normally need only `select` permission. The AI service writes conversation messages
through its internal connection.

## Auto-embedding configuration

| Operation | GraphQL field |
| --- | --- |
| Get one | `aiAutoEmbeddingsConfiguration` |
| List | `aiAutoEmbeddingsConfigurations` |
| Insert one | `insertAiAutoEmbeddingsConfiguration` |
| Update by primary key | `updateAiAutoEmbeddingsConfiguration` |
| Delete by primary key | `deleteAiAutoEmbeddingsConfiguration` |

Each configuration creates PostgreSQL search and similarity functions. The service assigns
camel-cased custom roots with an `Aggregate` suffix, such as `aiSearchMovies`,
`aiSearchMoviesAggregate`, `aiSimilarMovies`, and `aiSimilarMoviesAggregate`. See
[Auto-Embeddings](/products/ai/auto-embeddings) for a complete example.

## Legacy Graphite reference

Graphite's `graphite` remote-schema namespace and assistant operations are deprecated and are not
part of the current service. They remain documented separately in the
[Graphite GraphQL reference](/reference/graphql/graphite).
