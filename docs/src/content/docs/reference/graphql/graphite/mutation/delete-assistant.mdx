```graphql
deleteAssistant {

}: Boolean!
```

Delete an assistant

## Permissions needed

select (assistants):
- assistant_id
delete (assistants):


## Arguments



    - **`assistantID`** (`String!`): Assistant to delete



## Response

Type: `Boolean!`






**Request Example:**

```graphql title="query"
query deleteAssistant (
  $assistantID: String!
) {
  graphite {
    deleteAssistant (
      assistantID: $assistantID
    )
  }
}
```
