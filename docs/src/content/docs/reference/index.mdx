## Backend Services

The API reference for the authentication, storage, and AI services. Auth and Storage come with an **API Playground** to help you learn and test the endpoints against a local Nhost instance.

To learn how to start a local Nhost instance check out [local development](/platform/cli/local-development). Starting a local instance is optional and only required if you want to use the playground to simulate real requests.
