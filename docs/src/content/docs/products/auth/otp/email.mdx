One-Time Passwords (OTPs) are temporary codes for single use that can be delivered to users via email. OTPs expire after 5 minutes and can only be used once. OTPs can provide a more secure and convenient alternative to regular passwords.

To use One-Time Passwords, they need to be enabled in the configuration:

<Tabs>
 <TabItem label="nhost.toml">
 ```toml
 [auth.method.otp.email]
 enabled = true
 ```
 </TabItem>
 <TabItem label="Dashboard">
 ![sign-in otp](/images/auth/sign-in-otp.png)
 </TabItem>
</Tabs>

## Sign In

Signing in with an email OTP is a two-step process:

### Step 1: Request OTP

The user requests an OTP, which is sent to their email address:

<Tabs>
  <TabItem label="JavaScript">
  ```js
  await nhost.auth.signInOTPEmail({
    email: 'user@example.com',
  });
  ```
  </TabItem>

  <TabItem label="Dart">
  ```dart
  nhost.auth.signInEmailOTP(email: "user@example.com");
  ```
  </TabItem>
</Tabs>

### Step 2: Verify OTP

The user enters the OTP code received via email:

<Tabs>
  <TabItem label="JavaScript">
  ```js
  await nhost.auth.verifySignInOTPEmail({
    email: 'user@example.com',
    otp: '123456',
  });
  ```
  </TabItem>

  <TabItem label="Dart">
  ```dart
  nhost.auth.verifyEmailOTP(email: "user@example.com", otp: "123456");
  ```
  </TabItem>
</Tabs>

:::note
A user account is created the first time an email is used with OTP.
:::

## Elevate a Session

When email OTP is enabled, signed-in users can also use it to [elevate their session](/products/auth/elevated-permissions) before performing sensitive actions. The code is sent to the email address of the signed-in user using the same `signin-otp` template:

```js
await nhost.auth.elevateOTPEmail();

await nhost.auth.verifyElevateOTPEmail({
  otp: '123456',
});
```
