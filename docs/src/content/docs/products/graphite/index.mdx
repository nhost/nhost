:::caution[Deprecated]
Graphite is deprecated and has been superseded by [Nhost AI](/products/ai). Do not use Graphite for
new integrations. This section remains available only for maintaining existing Graphite
deployments.
:::

Graphite was Nhost's original AI service. It provided OpenAI-based auto-embeddings, a GraphQL remote
schema for Assistants, and generated GraphQL fields for vector search.

The current Nhost AI service replaces Graphite with:

- Multi-provider [Agents](/products/ai/agents) with SSE streaming and approval-aware tools
- Auto-embeddings stored in the `ai` schema with `ai`-prefixed configuration and function names
- Agent, session, and message data exposed through the project's generated GraphQL API instead of a
  Graphite remote schema

Graphite Assistants and Nhost AI Agents are not API-compatible. The current service also uses a
different database schema, GraphQL roots, webhook header, binary, and container image. Treat an
upgrade as a migration and test it before removing an existing Graphite deployment.
