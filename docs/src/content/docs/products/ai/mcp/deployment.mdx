The Backend MCP Server is a container image (`nhost/mcp`) that you deploy alongside your project using [Nhost Run](/products/run). Running it next to your GraphQL API keeps latency low and lets it reach the API over the internal network.

:::note
The examples use `nhost/mcp:0.4.0` and enable `storage-download`. Check the [releases page](https://github.com/nhost/nhost/releases) before deploying; the image tag must be published for the installer to work.
:::

## Before you deploy

Backend MCP relies on your Nhost Auth project being set up as an OAuth2 provider. Complete the [authentication prerequisites](/products/ai/mcp/authentication#prerequisites) — the OAuth2 provider, CIMD, and a consent page — before you deploy.

After clicking the link, edit the environment variables to match your project:

- **`MCP_AUTH_URL`** — your project's auth URL, for example `https://SUBDOMAIN.auth.REGION.nhost.run/v1` (or your custom domain).
- **`MCP_REALM`** — the public URL where Backend MCP will be reachable.
- **`MCP_GRAPHQL_ENDPOINT`** — the GraphQL endpoint Backend MCP forwards requests to.
- **`MCP_STORAGE_URL`** — defaults to `http://hasura-storage-service:5000/v1`, the project's internal Storage endpoint on Nhost Run. Remove it if you do not want to enable file downloads.
- **`MCP_INSTRUCTIONS`** — instructions that help the assistant understand your application.
- **`MCP_ENFORCE_ROLE`** — the role to enforce (for example `user_mcp`), or remove it to accept any role.

</TabItem>
<TabItem label="run-mcp.toml">

Add a `run-mcp.toml` file to your project directory:

```toml
name = 'mcp'
command = ['mcp']

[image]
image = 'nhost/mcp:0.4.0'

[[environment]]
name = 'MCP_AUTH_URL'
value = 'https://SUBDOMAIN.auth.REGION.nhost.run/v1'

[[environment]]
name = 'MCP_REALM'
value = 'https://mcp.acme.com'

[[environment]]
name = 'MCP_GRAPHQL_ENDPOINT'
value = 'http://hasura-service:8080/v1/graphql'

[[environment]]
name = 'MCP_STORAGE_URL'
value = 'http://hasura-storage-service:5000/v1'

[[environment]]
name = 'MCP_STORAGE_MAX_TRANSFER_BYTES'
value = '10000000'

[[environment]]
name = 'MCP_INSTRUCTIONS'
value = 'This MCP server interacts with my application'

[[environment]]
name = 'MCP_ENFORCE_ROLE'
value = 'user_mcp'

[[ports]]
port = 3000
type = 'http'
publish = true

[resources]
replicas = 1

[resources.compute]
cpu = 125
memory = 256
```

Then deploy Backend MCP:

```bash
nhost run config-deploy \
  --config run-mcp.toml \
  --service-id $SERVICE_ID
```

Once deployed, Backend MCP is reachable at its published port and any MCP-compatible client can connect. See [Connecting clients](/products/ai/mcp/clients).

## Enable storage downloads (optional)

Both Nhost Run examples set `MCP_STORAGE_URL` to `http://hasura-storage-service:5000/v1` and `MCP_STORAGE_MAX_TRANSFER_BYTES` to `10000000`. For deployments outside [Nhost Run's internal network](/products/run/networking), use the Storage URL for the **same backend**, including its API prefix (normally `/v1`).

Start with a 10 MB response limit for one download at a time. This does not limit concurrency. The server default of 50 MB can exhaust 256 MiB on a single call. See [Transfer limits](/products/ai/mcp/configuration#transfer-limits) before increasing the limit or allowing concurrent downloads. Leave `MCP_STORAGE_URL` unset to keep `storage-download` disabled.

Grant the token's role (for example `user_mcp` when using `MCP_ENFORCE_ROLE`) [Download permission](/products/ai/mcp/permissions#storage-permissions) for the files and buckets the assistant should be able to read.

## Run locally

To try Backend MCP against a local project, run it as part of your local stack:

```bash
nhost up --run-service run-mcp.toml
```

Point `MCP_AUTH_URL` and `MCP_GRAPHQL_ENDPOINT` at your local endpoints (for example `https://local.auth.local.nhost.run/v1`). For [storage downloads](#enable-storage-downloads-optional), use `https://local.storage.local.nhost.run/v1` if the service can't reach the internal Storage hostname.

## Configuration reference

Every setting can be supplied as a flag or an environment variable. `MCP_GRAPHQL_ENDPOINT` and `MCP_AUTH_URL` are required. See [Configuration](/products/ai/mcp/configuration) for the full list.
